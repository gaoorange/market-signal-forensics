# 信息真假、传播动机与价格行为

英文名：Market Signal Forensics

> **不判涨跌，只查三样：这话谁说的、谁受益、价格认不认。**

名字说的是它**查什么**（三个维度对应阶段 1–3、阶段 4、阶段 5），不是它**替你判什么**——
结论最高只到「高度可疑但不能定性操纵」，**不出真假判决**。

一个用于审查投资相关信息的 Agent Skill。它**不预测股价，不给买卖指令**，只做两件事：

- **识别**——这句话到底说了什么，哪些是可验证事实，哪些是预测、观点、修辞和缺失。
- **核验**——凭什么相信它，来源是什么等级，谁受益，有没有替代解释，下一步该查什么。

> 面向的读者是那种在群里收到一张截图、心跳开始加快、手指已经放在买入按钮上的人。
> 这个 Skill 的目标是让那只手先停三分钟。

---

## 它解决什么问题

信息本身很少直接说谎。更常见的是：

- **语义升级**——"计划投资"被读成"已经买入"，"战略合作"被读成"产生收入"，"中标候选"被读成"拿到订单"。
- **缺失分母**——"同比增长 300%"不说基数，"市占率领先"不说市场口径，"订单在手 10 亿"不说确认方式。
- **叙事标签**——"技术型牛市""估值修复""主力吸筹"这类没有定义的标签，被当成分析前提直接使用。
- **利益不透明**——发布者是否持仓、是否收费、是否持有空头、是否即将解禁，往往不在正文里。
- **文字强、行为弱**——公告很响，但经营现金流、回款、内部人交易和价格行为讲的是另一个故事。

这个 Skill 把上面五件事做成固定流程，每次都跑一遍，不靠临场发挥。

---

## 触发方式

装好之后，直接把材料丢给它就行。以下说法都会命中：

- 「这消息是真的吗」「这是利好还是利空」「这研报靠谱吗」
- 「是不是主力出货」「是不是在打压」「这是不是割韭菜」
- 「帮我看看这个公告」「这段电话会纪要有什么问题」
- 「这个大 V 说的能信吗」「他是不是在带节奏」
- 直接粘贴截图、链接、公告全文、研报片段或群聊记录

也可以显式点名：`用 market-signal-forensics 审查这条消息`。

## 审查流程

```
阶段 0  确定任务类型 ── 单条快审 / 多源交叉 / 公告 / 研报 / 传播链 / 价量 / 复盘
   │
阶段 1  拆分信息单元 ── FACT · CLAIM · FORECAST · OPINION · RHETORIC · MISSING
   │
阶段 2  验证来源等级 ── A 监管文件 → E 匿名截图，并区分"来源可靠"与"内容正确"
   │
阶段 3  识别语言游戏 ── 逐词标出模糊表述，补齐缺失的量化条件
   │
阶段 4  分析传播动机 ── 动机假设 · 可观察证据 · 替代解释 · 反证条件
   │
阶段 5  检查背后行动 ── 资本动作 / 内部人 / 财务质量 / 订单兑现 / 价量 / 传播行为
   │
阶段 6  输出审查结论 ── 五档结论 + 冷静检查区
```

**结论只有五档**，最高一档是「高度可疑但不能定性操纵」——上面没有「确认操纵」。
定性属于监管机构和司法机关，不属于一个 Skill。

## 输出长什么样

**输入**（虚构示例）：

> 【重磅】示例科技（虚构，代码从略）取得重大突破，成为行业唯一通过认证的供应商，
> 目前订单在手，公司积极推进产能扩张。当前 A 股已进入技术型牛市，该股严重低估。

**输出节选**：

| # | 原文摘录 | 标签 | 实际说了什么 | 缺什么才能确认 |
|---|---|---|---|---|
| 1 | 取得重大突破 | RHETORIC | 无技术、指标或验收方的具体描述 | 突破的是哪项指标、由谁验收 |
| 2 | 行业唯一通过认证 | CLAIM | 认证名称、发证机构、行业口径均未给出 | 认证名称与发证机构、"行业"的定义范围 |
| 3 | 订单在手 | MISSING | 未区分意向、框架协议还是已签生效合同 | 合同金额、客户是否具名、收入确认方式 |
| 4 | 积极推进产能扩张 | FORECAST | 进行中的意图，非已完成的事实 | 项目立项/环评/资本开支与投产时间表 |
| 5 | 已进入技术型牛市 | RHETORIC | 标签未定义，不能作为分析前提 | 指数、起算点、涨幅阈值、成交量、广度、持续时间 |
| 6 | 严重低估 | OPINION | 未给估值方法与可比对象 | 估值口径、历史分位、同行比较 |

**一句话结论**：全文 6 项陈述中 0 项达到 `FACT`，来源等级 `E`，关键金额与合同状态缺失——
当前证据不足以支持任何方向性判断，标记为**需要核验**。

**下一步验证清单**（节选）：查交易所公告平台是否有对应披露 → 查认证机构官网可否检索到该资质 → 查最近一期财报的合同负债与应收账款变动。

完整 10 节结构见 [`templates/signal-audit-report.md`](templates/signal-audit-report.md)。

## 局限性

写在前面，因为这些是这个 Skill **做不到**的事：

1. **不联网就没有实时数据。** 在没有联网检索能力的环境里，它只能审查你给的材料本身，所有需要外部数据的项都会标成"需查询"，不会替你填数。
2. **不能证明动机。** 动机永远是假设，不是结论。它能做的是把假设、支持证据和反证条件摆清楚。
3. **不能替代监管调查。** 它没有交易账户数据、通讯记录和账簿，够不到定性所需的证据层级。
4. **截图有天然上限。** 截图无法证明原帖存在、未被编辑、未被删改或未被断章取义。
5. **跨市场差异。** A 股、港股、美股在涨跌停、T+1、披露义务、做空机制和内部人申报窗口上都不同，同一指标含义会变，需要你先说明市场。
6. **不做预测。** 你问"能不能买""会不会涨"，它会把问题翻译成"需要验证什么"，然后把决定权还给你。
7. **对干净材料也照跑流程。** 面对合规、完整、可验证的公告，它应该给出"低风险/证据充分"，而不是硬凑怀疑——`tests/case_legitimate_announcement.md` 就是这个方向的对照组。
8. **产出物不是用来传播的。** 报告仅供你本人核验决策使用，不要公开发布、转发或截图外传；涉及真实自然人时 Skill 会主动匿名化，你也不该把匿名化的部分再填回去。

## 非投资建议声明

本项目是一套**信息审查方法论**，不是投资顾问服务。

- 本 Skill 及其输出不构成任何证券、基金、衍生品或其他金融产品的买入、卖出、持有建议，也不构成目标价、评级或投资组合建议。
- 本 Skill 不提供实时行情数据，输出中的任何数字都需要读者自行回到一手来源核对。
- 本 Skill 对任何个人、机构或公司不作违法定性。所有"存在诱导风险""动机无法排除"等表述均为**审查过程中的待验证假设**，不是事实认定，也不应被引用为对任何主体的指控。
- 使用者应自行判断并承担全部投资决策后果。若需要投资建议，请咨询持牌专业人士。
- 仓库中 `tests/` 目录下的全部材料、以及文档中出现的"示例科技"等主体均为**虚构**，与任何真实公司、机构或个人无关。
- 本仓库所有示例主体均只有名称、不带证券代码——任何 6 位数字代码都可能对应真实在用或曾退市的证券，因此一律不写。

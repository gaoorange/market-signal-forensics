# 模式化案例库（case-patterns）

> 用于 SKILL.md **阶段 4：分析传播动机**。当前材料"像"某种已知模式时，来这里比对。
> 本文件**不记录任何真实案件**：不写公司名、人名、年份、金额、案号、处罚文号、公告编号。
> 需要举例时一律使用明确标注的构造示例，例如「示例科技（虚构，代码从略）」。
> 需要查真实案例时，见文末「去哪里查真实案例」。

## 怎么用这个文件

每种模式固定分四节：

| 小节 | 作用 |
|---|---|
| 可确认的事实特征 | 这种模式通常在公开信息里留下什么**可查痕迹**（可落到 `FACT`，或至少是可核验的 `CLAIM`） |
| 可疑模式 | 哪些痕迹**组合出现**时应当提高警觉（单项出现不算） |
| 不能据此推出的结论 | 这些痕迹**不能证明**什么，尤其不能证明违法意图 |
| 核验动作 | 3—5 条具体可执行的查证步骤 |

三条硬约束，读这个文件时始终生效：

1. **模式匹配不是定性。** 本文件最高只能支持到 `高度可疑但不能定性操纵`，没有"确认操纵"这一档。
2. **每个动机假设必须配替代解释。** 本文件每种模式的"不能据此推出的结论"一节就是替代解释的最低配额，不得跳过。
3. **痕迹的证据等级要单独评。** "我在某平台看到有人说他提前建仓"是 `E` 级来源的 `CLAIM`，不因为它符合某个模式就升级为 `FACT`。

## 模式一：付费内容以独立研究体例发布，报酬披露不显著

**一句话形态**：内容以"独立研究""深度调研""价值发现"的体例出现，实际由被推荐方或其关联方付费或提供对价，且报酬关系未披露或披露得极不显眼。

### 可确认的事实特征

- 文章体例模仿卖方研究：有摘要、估值段落、风险提示，但**没有可核验的作者身份、执业资格或研究机构主体**。
- 披露声明的位置与措辞异常：正文热情洋溢，报酬说明放在页尾折叠区、图片里、超链接后面，或用"本文由某某支持""内容合作"等模糊表述替代具体金额与付款方。
- 同一账号或同一批账号在相近时间发布**结构高度一致**的多篇看多文章，只替换标的名称、行业词和数字。
- 文中数据大多来自被推荐方自己的宣传材料（`B` 级甚至 `E` 级），却被行文表述成既成事实。
- 传播路径可回溯：多篇转载指向同一原始出处，属于"同源转述"，不构成独立交叉验证。

### 可疑模式

以下若**同时出现三项以上**，可考虑升级为 `需要核验`；只有在同时具备价格或传播行为异常时才可到 `存在诱导风险`：

- 未披露或模糊披露报酬 + 结论强烈单向 + 全文无证伪条件。
- 大量 `FORECAST` 与 `RHETORIC` 被排版成 `FACT`（"预计将成为行业唯一"写成"已经是行业唯一"）。
- 估值段只给上行情景，不给下行情景，也不给假设敏感性。
- 发布时点集中在解禁、增发、配股、可转债、并购支付等**公司融资或减持窗口**附近。
- 评论区、转发链路由少量高度相似的新账号推动，文案高度雷同。

### 不能据此推出的结论

- **不能**推出"这家公司是骗局"或"内容全是假的"。付费推广的文章里也可能包含真实、可核验的事实。
- **不能**推出"作者与公司串通操纵市场"。收取内容费用本身在多数市场是合规行为，问题在**是否依规披露**，而披露义务的具体认定属于监管机构。
- **不能**推出"股价随后下跌就证明这是诱导"。价格走势不能反推发布者的主观意图。
- **不能**因为作者匿名就断定其有交易仓位；仓位需要独立证据，未披露 ≠ 已证实持有。

### 核验动作

1. 定位原始出处：把文章逐段回溯，确认多篇"独立报道"是否共用同一份通稿或同一原始作者；同源转述按**一个来源**计。
2. 全文检索披露关键词（报酬、赞助、内容合作、持仓、股份、期权、顾问费、compensation、sponsored），把找到的原文摘录进「来源与证据等级表」的"发布方利益关系"列。
3. 把文中每个数字回到一手文件核对：定期报告、交易所公告、监管备案。查不到的标为"未核实"，不要用记忆中的数字替代。
4. 检查发布时点与公司资本动作日历（增发、解禁、回购、股权激励）的相对位置，只描述时间关系，不下因果结论。
5. 在报告的「看多/看空两面分析」里，为该标的写出与文章方向相反的一组同样认真的证据与风险。

**常见落点等级**：多为 `需要核验`；披露缺失 + 传播异常 + 价格异动叠加时才到 `存在诱导风险`。

## 模式二：内容发布方向与其自述持仓方向一致，且无持仓变动记录

**一句话形态**：具备粉丝规模的创作者先自行买入，再向受众推荐同一标的，随后在受众买入形成的流动性中卖出；对外不披露自身仓位与交易安排。

### 可确认的事实特征

- 内容发布时间与标的的**成交量、换手率异常**在时间上重合，且异常出现在中小市值、流通盘较小的标的上更明显。
- 创作者过往内容存在可统计的规律：反复出现"我已经买了""重仓""不构成建议但我自己在做"等表述，但从不给出持仓变动记录。
- 部分平台要求利益披露，其披露栏为空或与内容不一致——这一点通常**可以直接截取原文核实**。
- 号召性语言密度高：倒计时、名额、错过、"最后的上车机会"、"明天就不是这个价了"。
- 内容里几乎不含证伪条件与退出条件——这是可直接观察的文本特征。

### 可疑模式

- 建仓类表述 + 强号召 + 不披露卖出 + 事后删帖或改帖。
- 同一创作者在短周期内高频轮换标的，每次都是"这次不一样"。
- 推荐集中在流动性差的标的上，少量资金即可显著推动价格。
- 收费社群/付费专栏内容与公开内容方向相反或存在时间差（先在小圈子讲，再对外喊）。
- 出现"放量不涨"或"高开低走"，同时传播强度仍在上升，即 SKILL.md 所说的**消息强、价格弱**。

### 不能据此推出的结论

- **不能**推出"他一定在出货"。创作者自己持有并公开看好，在披露充分时是常见且合规的做法。
- **不能**把"删帖"直接读成"心虚"。删帖也可能来自平台合规要求、事实更正或个人纠纷。
- **不能**用价格下跌反推其已卖出；除非有可核验的持仓变动记录，持仓变化只能是 `MISSING`。
- **不能**据此对具体个人作违法指控。是否构成违规取决于司法与监管的认定，不属于本 Skill。

### 核验动作

1. 建立时间线：把"内容发布时间"与"价格、成交量、换手率的异常时点"并排列出，明确标注哪些数据已查、哪些"数据缺失，未查询"。
2. 检索该创作者是否有任何公开的仓位披露、平台披露栏、合作声明，并原样摘录；找不到就写"未见披露"，不写"隐瞒"。
3. 用网页存档或平台自带的编辑记录核对是否存在删改；能证明的写 `FACT`，不能证明的写 `CLAIM`。
4. 评估标的的流动性口径（流通盘、日均成交额），判断"该规模的号召是否有可能影响价格"——这是可能性评估，不是事实认定。
5. 在动机表里同时写入善意动机（真心看好、内容流量本身即收益、并无交易安排）作为替代解释。

**常见落点等级**：`需要核验`；若"先建仓表述 + 未披露 + 价格异动 + 删改痕迹"多项叠加，可到 `高度可疑但不能定性操纵`。

## 模式三：发布方持有空头头寸，同时发布负面研究报告

**一句话形态**：发布方持有空头或看跌头寸，同时发布一份**事实基本经得起核对**的负面研究报告，报告的选材、时点与措辞都服务于其头寸方向。

### 可确认的事实特征

- 报告通常**明确披露**空头仓位（很多严肃的做空机构会在首页写明），这本身是可确认的 `FACT`，不是隐瞒。
- 报告大量引用一手材料：监管备案、工商登记、法院文书、卫星或现场照片、供应链访谈；这些引用**可逐条回查**。
- 报告的结构偏向"最坏情形"：只呈现支持看空的证据链，几乎不给反向证据的权重。
- 发布时点常选在流动性充足的交易时段或解禁、财报窗口附近——时点可查，因果不可推断。
- 被指控方通常会发澄清公告，两份文件的**争议焦点是否正面对撞**是可以逐条比对的。

### 可疑模式

- 已披露空头 + 结论强度远超证据强度（用若干笔可疑交易推出"整体造假"）。
- 关键指控依赖匿名访谈（`C`—`E` 级）而非可回查文件（`A` 级）。
- 使用"我们相信""我们估计"包装的推断，被排版成与文件证据同等地位。
- 报告发布后短时间内出现大量结构雷同的二次传播，且传播文案比原报告更绝对。
- 对同一事实的两种解释被系统性地只保留不利的一种（选择性事实）。

### 不能据此推出的结论

- **不能**因为发布方有空头就推出"内容是假的"。**利益相关不等于事实错误**，事实要一条一条自己核。
- **不能**因为内容多数属实就推出"因此整体结论成立"。真实的局部事实可以支撑一个被放大的整体结论。
- **不能**推出"这是恶意做空"。按 SKILL.md 红线表，只能写"发布者披露/未披露空头仓位，其利益关系与结论方向一致，动机无法排除"。
- **不能**把公司的澄清公告自动当作反驳成立；澄清同样是**单方面陈述**，是 `A` 级来源的 `CLAIM`。

### 核验动作

1. 把报告的指控拆成独立条目，逐条标注证据等级（`A`—`E`）和是否可自行回查，形成一张"指控—证据—可回查性"表。
2. 只挑**最关键的 2—3 条**（推翻它们就推翻整体结论的那几条）去回查一手文件，不要平均用力。
3. 逐条比对公司澄清公告是否**正面回应**了那 2—3 条；对"没有回应的部分"单独列出，标为 `MISSING`。
4. 检索是否存在与报告方无关的第三方独立验证（独立审计、监管问询回复、法院文书），注意区分独立来源与同源转述。
5. 在报告里同时写出"如果指控成立，未来财报/公告中应出现什么"与"如果指控被夸大，最先暴露的指标是什么"两组证伪条件。

**常见落点等级**：视回查结果分布在 `需要核验` 与 `存在诱导风险` 之间；披露完整、证据以 `A` 级为主时也可能是 `低风险/证据充分` 的负面事实陈述。

## 模式四：机构持仓披露被二次转写为当前买入信号，基准日与分母缺失

**一句话形态**：某大型机构的持仓披露（季度持仓报告、权益变动报告、指数基金再平衡等）被媒体和社交平台转写成"某某巨头重仓押注某某"，读者据此当作**当前**的买入信号。

### 可确认的事实特征

- 持仓披露文件本身是 `A` 级来源，**但它描述的是过去某个基准日的静态快照**，天然存在时滞。
- 文件通常不区分主动配置与被动跟踪：指数纳入、ETF 申赎、做市、对冲腿、可转债对应的股票头寸都会混在同一张表里。
- 文件一般不含成本价、不含建仓时间、不含后续是否已减持——这些是结构性的 `MISSING`，不是"公司隐瞒"。
- 二次传播的标题几乎必然做了三件事：去掉基准日、去掉占比分母、把"持有"写成"押注/加仓/看好"。
- 同一份披露会被几十家媒体同时转写，属于典型的**同源转述**，看起来像多来源交叉验证，实际只有一个来源。

### 可疑模式

- 标题出现"抄作业""跟着聪明钱""巨头出手"等叙事标签，正文却查不到基准日与占比。
- 用绝对金额制造冲击力（"数亿元重仓"），不给该头寸占其组合的比例，也不给占标的流通盘的比例。
- 把一次性的**新增披露**说成"持续加仓"，或把机械的指数再平衡说成"主动看好"。
- 传播集中在开盘前，且随后出现高开低走。
- 一段时间后出现减持披露时，二次传播链条**集体沉默**。

### 不能据此推出的结论

- **不能**推出"机构现在还持有"。披露有时滞，当下仓位属于 `MISSING`。
- **不能**推出"机构看好该股"。持仓可能来自被动跟踪、对冲、做市或衍生品对应头寸。
- **不能**推出"媒体在配合出货"。多数情况下更合理的替代解释是**流量驱动的机械转写**，传播者未必有交易动机。
- **不能**把"跟随大机构"当作风险控制手段；机构的持有期限、成本、组合分散度与个人投资者完全不可比。

### 核验动作

1. 找到原始披露文件本身（监管系统或交易所的信息披露平台），核对基准日、披露口径、报告主体。
2. 计算两个分母：该头寸占其组合的比例、占标的流通盘的比例；分母缺失的报道直接降级处理。
3. 检索同一主体的历史披露序列，看这是新增、维持还是减少，避免用单期快照讲趋势。
4. 判断该头寸是否可能来自被动或对冲用途（标的是否属于主流指数成分、披露主体是否为指数产品管理人）。
5. 把所有转写文章回溯到原始出处，在「来源与证据等级表」里合并为一个来源，并注明"同源转述"。

**常见落点等级**：多为 `需要核验`；媒体转写严重变形且伴随开盘前集中传播时可到 `存在诱导风险`。

## 模式五：热点期内概念相关表述密集发布，可量化字段缺席

**一句话形态**：在某个概念、政策或热点爆发期，主体密集释放与该概念**语义相关但业务实质薄弱**的信息（互动平台回复、宣传稿、非约束性协议），使自身被归入热点板块。

### 可确认的事实特征

- 信息载体本身可查：互动问答平台的提问与回复、公司官网新闻稿、非约束性的框架协议或战略合作公告。
- 措辞普遍停留在 SKILL.md 阶段 3 的"进度模糊词"层：**关注、布局、储备、已有技术积累、正在接触、可应用于**。
- 与之相对，可量化字段系统性缺席：金额、期限、客户名称、产能、收入确认方式、是否已签署且生效。
- 频率可统计：短周期内同类表述的**发布密度**明显高于该主体的历史基线。
- 后续定期报告中，该概念相关收入往往**没有单独列示**，或占比极低——这一点在财报出来后可直接核对。

### 可疑模式

- 高密度概念表述 + 零可量化字段 + 股价短期大幅波动 + 随后出现减持、解禁或增发。
- 同一集团内多个主体在同一热点上轮流发声。
- 出现交易所问询函或关注函（这本身是 `A` 级可查事实），而回复内容进一步弱化了原表述。
- 宣传口径与定期报告口径不一致：宣传说"核心供应商"，报告里该业务不构成主要业务。

### 不能据此推出的结论

- **不能**推出"公司在编造业务"。技术储备、早期接触、探索性投入都是真实存在的经营活动。
- **不能**推出"公司故意配合股价"。发布节奏与热点重合的替代解释包括：行业窗口期确实来了、投资者提问集中、同业都在披露。
- **不能**因为业务占比小就认定披露违规；披露是否恰当由交易所和监管机构判断。
- **不能**把"股价涨了"当作公司意图的证据。

### 核验动作

1. 把所有相关表述按时间排成一张表，逐条标注 `FACT` / `CLAIM` / `FORECAST` / `RHETORIC`，并列出每条缺失的量化字段。
2. 到交易所信息披露平台检索该主体是否收到问询函/关注函，以及回复中对同一事项的表述是否被削弱。
3. 在最近的定期报告里检索该概念关键词，看是否有独立的收入、产能或客户披露；没有就写"报告中未单独列示"。
4. 对照公司资本动作日历（解禁、减持、增发、可转债），只陈述时间关系。
5. 设定事后验证点：下一期定期报告中该业务应出现的最小可观测变化是什么，写进「下一步验证清单」。

**常见落点等级**：`需要核验`；概念表述 + 资本动作窗口 + 价格异动叠加时可到 `存在诱导风险`。

## 模式六：澄清公告成为传闻的主要分发渠道

**一句话形态**：一则传闻先在小范围流传，公司随后发布澄清或说明公告；公告本身是合规行为，但它把原本小众的传闻**放大成全市场可见的信息**，并可能在措辞中留下暧昧空间。

### 可确认的事实特征

- 澄清公告是 `A` 级来源，公告文本可逐字引用，是本模式中最扎实的可查证据。
- 传闻的原始传播范围与澄清后的传播范围可对比：澄清公告经常成为传闻的**最大分发渠道**。
- 措辞层次可以逐句分级："不存在应披露而未披露的事项"、"目前尚未签署"、"存在不确定性"、"不排除"——每一句的约束力都不同。
- 常见的暧昧结构：**否定的是当下状态，不否定未来可能性**（"截至本公告日尚未……"）。
- 公告与后续实际动作是否一致，可在后续公告与定期报告中核对。

### 可疑模式

- 澄清文本表面否认、实际给"未来可能发生"留门，且这一句被二次传播单独截出来放大。
- 澄清发布后价格不跌反涨，同时出现集中转发，转发文案普遍只引用留门那一句。
- 澄清与前一次公开表述存在口径漂移，但公告未解释差异。
- 澄清时点集中在开盘前或收盘前，且与解禁、减持、增发窗口接近。
- 后续实际发生的事项与澄清中的否认部分不一致，而未见更正说明。

### 不能据此推出的结论

- **不能**推出"公司自己放的传闻"。发布澄清是**法定或规则要求的披露义务**，最常见的解释就是合规履职。
- **不能**推出"澄清等于事情不存在"。澄清是公司单方面陈述，属于 `A` 级来源的 `CLAIM`。
- **不能**推出"澄清等于事情存在"。"不排除"是标准的法律免责措辞，不构成暗示。
- **不能**因为价格上涨就认定澄清具有诱导性；价格由多重因素驱动。

### 核验动作

1. 只用公告原文做分析：逐句摘录，标出时间限定词（截至……日）、状态限定词（尚未、暂无）、可能性词（不排除、存在不确定性）。
2. 与该主体此前对同一事项的公开表述逐句对照，列出口径差异，不解释动机只陈述差异。
3. 检索传闻的最早可查出处及其证据等级；找不到出处就写"原始出处不可考"，不得把传闻写成事实。
4. 记录传播时序：传闻出现时间、公告发布时间、集中转发时间、价格与成交量变化时点。
5. 设定事后验证点：若澄清中的否认为真，后续 1—2 个报告期内应当**不出现**哪些公告或科目变化。

**常见落点等级**：多为 `低风险/证据充分` 或 `需要核验`；仅当留门措辞 + 集中转发 + 资本动作窗口叠加时才谈 `存在诱导风险`。

## 去哪里查真实案例

本文件不复述任何真实案件。要看真实的、已被认定的案例，请到官方入口自行检索——**以官网当期栏目名称为准**，不要引用二手转述。

**一手披露入口的权威清单见 `references/evidence-and-source-hierarchy.md` 第七节**（境内监管机构、交易所、法定披露平台、EDGAR 等），此处不再复制，避免多处副本漂移。

本文件只额外保留境外执法与投资者警示的检索入口：

| 入口 | 检索什么栏目 |
|---|---|
| 美国 SEC https://www.sec.gov | 在官网检索 Litigation Releases、Administrative Proceedings 栏目 |
| 美国 SEC 投资者教育 https://www.investor.gov | 在官网检索投资者警示与欺诈识别专题 |
| 美国 FINRA https://www.finra.org | 在官网检索 Investor Alerts 与纪律处分（Disciplinary Actions）栏目 |

使用规则：

- 引用真实案例时，**必须给出可点击的一手来源**，并逐条区分"监管机构认定的事实"与"当事人主张"。
- 给不出来源就**不写具体细节**（不写公司名、金额、日期、文号），只写抽象模式。
- 监管处罚决定认定的是**该案的事实**，不能外推到任何其他主体；"模式相同"不构成对新主体的指控。
- 引用时注意状态：调查中、已作出决定、正在复议或诉讼中，三者含义完全不同，不得混写。

## 模式相似 ≠ 事实相同

这是本文件最重要的一节。

模式匹配的作用是**提出问题**，不是**给出答案**。上述六种模式描述的都是"在公开信息里能观察到的痕迹组合"，而痕迹组合与违法事实之间隔着至少三道无法靠阅读文本跨越的鸿沟：

1. **意图无法从文本反推。** 同一段措辞可以出自诱导，也可以出自法务审慎、翻译不当、写作水平或行业惯例。本 Skill 不做意图认定。
2. **相关不等于因果。** 发布时点与价格异动重合，可能是消息影响价格，可能是价格异动引发了消息，也可能两者同受第三个因素驱动（指数调整、行业事件、宏观数据）。
3. **样本选择偏差。** 事后回看时，我们只记得"符合模式且随后出了事"的案例，看不见大量"符合模式但一切正常"的案例。用模式做预测，假阳性会远高于直觉。

因此，当材料匹配某一模式时，正确的写法是：

- 写"该材料在措辞、披露与传播时序上符合模式 X 的若干特征"，并**逐条列出匹配了哪几条、未匹配哪几条**。
  未匹配项**必须与匹配项写在一起**，只列匹配项等于把"像"写成了"是"。
  示例写法："符合模式一的第 1、2、4 条（体例模仿研究报告、报酬说明位置不显著、数据多来自被推荐方宣传材料）；未匹配第 3、5 条（未见同批账号批量发布结构一致的文章，也未见同源转载链路）。"
- 同时写出至少一个能解释相同痕迹的**善意替代解释**。
- 写出**反证条件**：出现什么证据，这个模式假设就被推翻。
- 结论等级最高只能到 `高度可疑但不能定性操纵`；材料不足或来源冲突时，诚实地写 `无法判断`。

不得出现的写法（对照 SKILL.md 第一节红线表）："这就是模式 X，所以是操纵""历史上这种套路都是出货""模式吻合度 90%"。
定性属于监管机构和司法机关，不属于本 Skill；本文件的全部价值，是让下一步的核验动作更有针对性。

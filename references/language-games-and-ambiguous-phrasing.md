# 语言游戏与含糊表达词典

> 对应 SKILL.md 阶段 3。遇到模糊词、叙事标签、最高级话术、缺分母的数字或否定式承诺时查本词典。
> 本文件只做**语义还原**：把一句好听的话翻译回它在证据上真正支持的范围。
> 它不判断涨跌，不判断真假，也不认定任何主体在"操纵市场"。

---

## 零、怎么用这份词典

### 四步操作

1. **划词**：通读原文，把命中本词典的词逐个圈出来，连同它所在的整句一起摘录（脱离上下文的单词无法判断）。
2. **还原**：按"真正可能含义"一栏把整句改写成中性句，比较改写前后读者预期的落差。落差越大，包装程度越高。
3. **列缺口**：把"缺失信息"一栏落到**具体可查的对象**上——哪份文件、哪个报表科目、哪个字段、哪个披露平台。写不出可查对象的缺口，等于没提。
4. **出问题**：把"验证问题"改写成可以直接发给公司、券商或作者的一句话提问，进入报告第 8 节『下一步验证清单』。

### 输出对接

阶段 3 的四列表（原文 / 表面含义 / 缺失条件 / 可验证问题）直接由本词典的第 2、3、4 列填充；
"风险等级"一列用于给"下一步验证清单"排序：**高 > 中 > 低**，同级时按"最能改变结论"优先。

### 五条原则

1. **先定位，再降级**：先确认词条命中，再决定标签，不要跳过还原步骤直接下判断。
2. **落到标签**：每个词条命中后，对应陈述通常只能打 `CLAIM` / `FORECAST` / `RHETORIC` / `MISSING`，不能打 `FACT`。只有当"缺失信息"一栏被一手文件补齐后，才可能升级为 `FACT`。
3. **落到证据等级**：词条本身不产生证据等级。公司公告里的模糊词仍是 `A` 级来源，但内容只是 `CLAIM`；自媒体转述里的同一个词是 `E` 级来源的 `RHETORIC`。**来源可靠 ≠ 内容正确。**
4. **落到结论等级**：单个模糊词最多支撑到 `需要核验`。只有"模糊叙事 + 利益关系不透明 + 传播或价格行为异常"三者叠加，才可能到 `存在诱导风险`；多项组合证据才可能到 `高度可疑但不能定性操纵`。词典本身永远不能直接得出 `高度可疑但不能定性操纵`。
5. **不得反向滥用**：命中词条只说明"这句话没说清楚"，不说明"说话的人在骗人"。合规公告为了避免误导，本来就大量使用"拟""意向""不确定性提示"，这属于正常披露语言，应结合上下文判断，不能一见模糊词就升级怀疑。

### 风险等级定义

| 等级 | 含义 |
|---|---|
| **高** | 极易被读者读成已兑现的事实，且与真实含义之间存在实质性落差；常出现在诱导型传播中，必须逐项补齐"缺失信息"后才可引用 |
| **中** | 有明确的合规或行业用法，但容易被二次传播剥离限定条件；需要标注限定条件后才可引用 |
| **低** | 多为语气或叙事修饰，本身信息量低；标记为 `RHETORIC` 后可以直接从分析前提中剔除，不必深挖 |

### 组合放大规则

以下组合出现时，整体风险等级比单个词条**上调一级**：

- 进度模糊词（A 组）+ 具体大额数字，但数字不带确认口径（D 组）。
- 行情叙事标签（B 组）被当作**分析前提**而不是被分析对象。
- 最高级话术（C 组）+ 无法检索到的口径限定（"某细分领域全球第一"）。
- 否定式承诺（E 组）+ 该承诺涉及的主体近期有资本运作或解禁安排。
- 同一段文字中 A/C/D 三组各命中两个以上，且全文没有任何可回溯的一手文件编号或链接。

### 跨组复合话术（识别到即整体上调一级）

| 复合形态 | 典型结构 | 为什么危险 |
|---|---|---|
| 模糊进度 + 硬数字 | "拟签署框架协议，金额上限 X 亿元" | 硬数字让整句读起来像事实，但真正被约束的只有"上限"两个字 |
| 叙事标签 + 时间压迫 | "技术型牛市已确立，窗口期有限" | 用未定义的标签制造紧迫感，压缩读者的验证时间 |
| 最高级 + 自定义口径 | "某细分领域全球唯一" | 口径由发布方自选，外部无法证伪也无法比较 |
| 否定承诺 + 资本运作 | "无减持计划"与增发、解禁、质押安排同期出现 | 承诺无期限，而资本运作有明确时间表，两者不对等 |
| 剔除法 + 可比口径 | "剔除一次性因素后，按可比口径增长 X%" | 两层口径调整叠加，法定报表数字被完全遮蔽 |

出现复合形态时，在阶段 3 的表中**单列一行**记录整个组合，而不是拆成互不相干的单词。

## A. 进度与承诺模糊词

这一组的共同点：**把"可能性、意向、早期阶段"表述得接近"已完成"**。

**组内快速三问**：

1. **法律状态**——签没签、生没生效、有没有约束力、能否单方退出？
2. **金额口径**——含税否、跨几年、是否为上限、是否可变更或取消？
3. **兑现路径**——什么时候、以什么科目、进哪一张报表？

**商务进度阶梯**（从弱到强，越靠左离收入越远，跨级转写即为语义升级错误）：

> 接触客户 → 送样 → 通过验证 → 进入合格供应商名录 → 中标候选 → 正式中标 → 签署合同 → 交付 → 收入确认 → 回款

**本组对应的语义降级铁律**（与 SKILL.md 阶段 1 一致，出现即须在报告中指出）：

| 原文实际含义 | 常见错误升级 |
|---|---|
| 计划投资 / 拟投资 | 已经买入 |
| 接触客户 / 送样 / 中标候选 | 获得订单 |
| 战略合作 / 签署框架协议 / MOU | 产生收入 |
| 同比改善 | 绝对水平健康 |
| 账面盈利 | 现金流良好 |
| 不排除进一步投资 | 已决定投资 |
| 考虑回购 | 确定回购 |
| 提交注册 / 受理 | 获批 |
| 通过验证 / 进入测试 | 进入量产 |
| 在手订单（本组补充） | 本期收入 |

| 词条 | 常见包装方式 | 真正可能含义 | 缺失信息 | 验证问题 | 风险等级 |
|---|---|---|---|---|---|
| 有望 | "有望成为核心供应商""有望贡献可观业绩" | 说话人的期待，可能连内部立项都没有；不构成任何承诺 | 概率依据、时间表、达成条件、谁给的判断 | 这个"有望"是公司披露的，还是撰稿人加的？依据是哪份文件？ | 高 |
| 或将 | "或将迎来订单放量""或将纳入指数" | 纯推测句式，常用于规避事后追责 | 触发条件、决策方、决策时点 | 去掉"或将"后这句话还成立吗？如果不成立，它就是 `FORECAST` | 高 |
| 预计 | "预计全年营收增长显著" | 谁的预计？公司指引、分析师模型还是作者估算，三者可靠性完全不同 | 预计主体、假设前提、上下限区间、历史预计的兑现率 | 该主体过去三期的"预计"实际兑现了多少？ | 中 |
| 计划 | "计划投资 X 项目""计划扩产" | 内部意图，未必已过董事会、未必已签合同、未必已支付 | 审议程序进度、资金来源、开工或付款节点、可取消条件 | 有没有对应的董事会决议或投资协议？款项是否已支付？ | 高 |
| 拟 | "拟收购""拟增资""拟签署" | 法律上的**未完成态**，是本组最容易被读成"已完成"的字 | 生效条件、审批环节、交割先决条件、终止条款 | 从"拟"到"完成"还差哪几步？任何一步未过就不算落地 | 高 |
| 意向 | "达成合作意向""意向订单" | 通常无强制执行力，可单方退出 | 是否具有约束力、违约责任、有效期 | 文件里有没有"不具有法律约束力"这类表述？ | 高 |
| 框架协议 | "签署战略框架协议，金额上限 X 亿" | 只约定合作方向与上限，不等于实际采购量，落地率可能远低于上限 | 具体订单、执行期、最低采购量、定价机制 | 框架下已经产生了多少张实际订单？金额多少？ | 高 |
| 战略合作 | "与行业龙头达成战略合作，深度赋能" | 可能只是一份联合声明或备忘录，甚至只是互相挂名 | 合作内容、排他性、金额、期限、双方投入 | 对方公司是否在自己的渠道同步披露？口径是否一致？ | 高 |
| 深度绑定 | "与头部客户深度绑定" | 营销措辞，通常无对应法律安排；也可能反向意味着客户集中度风险 | 是否有长期协议、股权关系、排他条款、该客户收入占比 | 这属于"绑定"还是"依赖单一大客户"？占比多少？ | 高 |
| 积极推进 | "相关工作正在积极推进中" | 高频兜底用语，几乎不含增量信息，常用于回应问询而不给进度 | 当前所处阶段、里程碑、下一节点时间 | 与上一期公告相比，"推进"到了哪一步？有变化吗？ | 中 |
| 持续加码 | "持续加码新业务" | 可能只是小额追加，也可能是过去投入的重复表述 | 累计投入金额、本期新增额、资本开支占比 | 现金流量表里的购建固定资产支出是否同步增加？ | 中 |
| 重大突破 | "技术取得重大突破" | 可能是实验室指标、样品、专利申请，而非可量产、可销售 | 突破的具体指标、验证方、所处阶段、量产时间 | 是谁验证的？有没有第三方检测报告或客户认证？ | 高 |
| 进入供应链 | "已进入某巨头供应链" | 可能只是进入合格供应商名录，尚无实际采购单 | 是否有采购订单、供货份额、独家或多供、起量时间 | 名录资格与实际订单是两件事，目前是哪一件？ | 高 |
| 送样 | "已向客户送样" | 商务流程的**早期**环节，之后还有验证、认证、小批量、量产多关 | 送样数量、客户名称、验证周期、通过率、后续排产 | 送样之后的下一个节点是什么？何时能知道结果？ | 高 |
| 通过验证 | "已通过客户验证""通过测试" | 只说明技术指标达标，不等于拿到订单、更不等于进入量产 | 验证范围、是否小批量、订单是否下达、产能是否就绪 | 验证通过到收入确认之间，还差哪几个环节？ | 高 |
| 中标候选 | "成为项目中标候选人" | 公示阶段，仍可能被质疑、废标或调整 | 公示期、是否第一候选、最终中标公告、合同签署 | 有没有正式中标通知书和已签合同？ | 高 |
| 提交注册 | "已提交注册""已受理" | 只是材料被接收，尚未获得批准 | 审批阶段、平均审批周期、补正次数、被否风险 | 主管部门的公开进度页面显示当前处于哪个状态？ | 高 |
| 订单在手 | "在手订单充足，业绩确定性强" | 在手订单是**合同口径**，不等于收入，可能跨多年、可能被取消或变更 | 订单总额、执行周期、年度可确认部分、取消与变更条款、客户信用 | 在手订单中今年能确认收入的有多少？合同负债和应收账款怎么走的？ | 高 |
| 获得认可 | "获得客户/市场高度认可" | 通常无可核验主体，可能来自内部评价或付费评选 | 认可主体、评价标准、是否付费、是否有对应订单 | 认可方是谁？这份"认可"是否伴随实际采购？ | 中 |
| 行业领先 | "技术行业领先""规模行业领先" | 未定义"行业"边界与"领先"维度，口径可自选到自己第一为止 | 行业定义、统计口径、数据来源、对比样本、时间截面 | 按哪家第三方口径、哪个指标、哪一年？换一个口径还领先吗？ | 高 |
| 显著增长 | "业绩显著增长" | "显著"无标准；低基数下的高增速与绝对水平健康是两回事 | 基期数值、绝对金额、同行同期增速、是否含并表或一次性因素 | 增长的绝对额是多少？剔除并表和一次性损益后还剩多少？ | 高 |
| 价值重估 | "公司迎来价值重估" | 是对**估值倍数**变化的期待，属于观点，不是经营事实 | 重估依据、对标公司、可比倍数、当前隐含增长率 | 重估的前提假设是什么？假设不成立时估值回到多少？ | 中 |
| 严重低估 | "当前股价严重低估" | 观点，且高度依赖发布者自选的估值模型与对标 | 使用的估值方法、关键假设、发布者持仓与利益关系 | 换一种估值方法或换一组对标，结论是否反转？ | 中 |

## B. 行情叙事标签

这一组的共同点：**用一个听起来有技术含量的名词，替代对当前市场状态的定义与举证**。

**处理原则**：叙事标签只能作为**被分析的对象**，不能作为**分析的前提**。凡是没有给出可核验定义的标签，一律按 `RHETORIC` 处理。

**组内快速三问**：

1. **定义**——这个标签的判定规则是什么？谁定的？换一组参数还成立吗？
2. **证伪**——什么情况出现就算这个判断错了？提出者事先写过这个条件吗？
3. **对称性**——同一组数据的相反解释是什么？两种解释靠什么区分？

**双向可解释性检验**：本组多数标签的特征是"涨了这样说、跌了那样说"。审查时把标签放进两种情形里各念一遍——

| 数据事实 | 看多叙事 | 看空叙事 | 二者靠什么区分 |
|---|---|---|---|
| 指数上涨、多数个股下跌 | 结构性牛市 | 上涨集中于少数权重股，广度恶化 | 涨跌家数比、等权与市值加权指数收益差 |
| 放量下跌 | 洗盘、黄金坑 | 承接不足、抛压释放 | 可核验的持股或席位变动数据 |
| 缩量横盘 | 缩量企稳、主力吸筹 | 成交意愿枯竭 | 后续放量方向、持股人数变化 |
| 越过某涨幅阈值后回落 | 牛市未完 | 原判断已被证伪 | 提出者事先设定的证伪线 |

两种叙事都能套上同一组数据时，说明该数据**不具备区分能力**，此时任何一侧的结论都只能标 `无法判断`。

| 词条 | 常见包装方式 | 真正可能含义 | 缺失信息 | 验证问题 | 风险等级 |
|---|---|---|---|---|---|
| 技术型牛市 | "指数已进入技术型牛市，趋势确立" | 一个**阈值标签**，不含任何关于未来方向的信息；详见下方第六节 | 指数或标的、起算点、涨幅阈值、成交量、市场广度、持续时间、基本面背景（七项） | 七项定义能否逐项写出来？缺任意一项即降为 `RHETORIC` | 高 |
| 结构性牛市 | "虽有分化，但仍是结构性牛市" | 通常等价于"少数标的上涨、多数下跌"，即**大部分持仓其实在跌** | 上涨家数占比、指数与中位数个股收益差、行业集中度 | 涨跌家数比是多少？等权指数与市值加权指数走势差多少？ | 高 |
| 慢牛 | "慢牛格局不变" | 对"涨得慢"和"跌下去了但会回来"的同一套说辞，事后可双向解释 | 时间尺度、回撤容忍度、失效条件 | 什么样的回撤幅度或持续时间出现，就算"慢牛证伪"？ | 中 |
| 长牛 | "开启十年长牛" | 超长期预测，在可验证周期内**不可证伪**，因此不具备决策信息量 | 检验周期、中途失效条件、提出者的历史记录 | 这个判断在多长时间内可以被证明是错的？ | 中 |
| 牛市未完 | "调整只是插曲，牛市未完" | 把回撤重新定义为"过程"，使原判断免于被证伪 | 原判断的证伪条件、本次回撤是否触发过该条件 | 提出者此前设定的止损或证伪线是什么？现在触发了吗？ | 高 |
| 估值修复 | "板块估值修复行情启动" | 假设"当前估值偏低且会回到某个中枢"，两个假设都需要单独举证 | 参照中枢的时间区间、可比公司、盈利预测是否同步下修 | 估值低是因为便宜，还是因为盈利预期正在下修（分母在缩）？ | 高 |
| 底部反转 | "确认底部反转" | "底部"只能事后确认；实时使用时是**预测**，不是描述 | 反转的判定规则、失败后的处理、历史误判率 | 用同一套规则回看过去，它给出过多少次错误的"底部"？ | 高 |
| 黄金坑 | "这是主力挖的黄金坑" | 把下跌重新叙述成利好，属于典型的**不可证伪包装** | 与"趋势走坏"的区分标准 | 如果这不是"黄金坑"而是趋势转弱，观察上会有什么不同？ | 高 |
| 洗盘 | "只是洗盘，不是出货" | 对同一段下跌的两种相反解释之一，仅凭价格无法区分 | 筹码分布、成交明细、席位或持股变动数据 | 有没有可核验的持股变动数据支持"洗盘"而不是"减持"？ | 高 |
| 主力吸筹 | "主力正在低位吸筹" | "主力"通常无明确定义，散户可见数据难以识别真实买方 | "主力"的定义、数据来源、统计方法、样本期 | 这个判断基于哪份公开数据？该数据能否区分买卖方身份？ | 高 |
| 聪明钱 | "聪明钱正在流入" | 多为对某类资金流指标的重新命名，指标本身可能滞后或口径含糊 | 指标定义、数据来源、历史胜率、滞后期 | 该指标过去的信号准确率如何？是否经过样本外检验？ | 中 |
| 机构抱团 | "机构抱团加固/瓦解" | 对持仓集中度的描述被当作方向判断使用 | 统计口径（哪类机构、哪个报告期）、集中度数值、数据滞后期 | 持仓数据的报告期距今多久？期间是否已发生变化？ | 中 |
| 缩量企稳 | "缩量企稳，下跌动能衰竭" | 对成交量下降的乐观解读；同样的数据也可解读为"承接意愿不足" | 成交量的对比基准、企稳的判定标准、失败条件 | 同一组量价数据的看空解释是什么？两种解释怎么区分？ | 中 |

## C. 最高级与稀缺性话术

这一组的共同点：**通过不断缩小定语范围，把任何主体都做成"第一"**。

**四要素检验**：**在什么口径下、由谁统计、哪个时间截面、对比样本是谁。** 四项缺一，最高级即失效，降为 `RHETORIC`。

**定语剥离法**：把限定词从最窄往最宽逐层去掉，看"第一"在第几层失效。

> 例（构造示例）："国内华东地区某细分工艺路线产能最大的独立第三方厂商"
> 剥离一层 → 国内该细分工艺路线产能最大？剥离两层 → 国内该大类产品产能最大？剥离三层 → 国内该行业产能最大？

通常在剥离一到两层后即不再成立。**在报告中写明它在哪一层失效**，比单纯说"这是宣传语"更有信息量。

**"首次"的三重误读**（本组最高频误读，须逐条拆开）：

- 误读一：首次 = 大额。实际可能是极小的试探性头寸。
- 误读二：首次 = 看好。实际可能是被动跟踪指数、做市或对冲需要。
- 误读三：首次 = 长期。实际可能无锁定期，下一报告期即可清仓；且持仓数据本身有披露滞后。

| 词条 | 常见包装方式 | 真正可能含义 | 缺失信息 | 验证问题 | 风险等级 |
|---|---|---|---|---|---|
| 首次 / 首次投资 | "首次投资该赛道""知名机构首次建仓" | 首次≠大额，也≠看好；可能是极小的试探性头寸或被动配置 | 金额、占其组合比重、占标的流通盘比例、是否主动管理、锁定期 | 这笔"首次投资"占投资方总资产多少？占标的流通股本多少？ | 高 |
| 最大 | "国内最大的某某基地" | 通常靠限定词堆叠得出（地域+细分+口径） | 统计口径、限定词、第三方来源、统计时点 | 把限定词逐个去掉后，这个"最大"还成立吗？ | 中 |
| 领先 | "技术水平领先同行" | 无量化指标的自我评价 | 对比指标、对比对象、测量方法、第三方验证 | 领先多少？用哪个可测指标？谁测的？ | 中 |
| 唯一 | "行业唯一具备该能力的企业" | 常见于自述；"唯一"往往依赖极窄的定义 | 定义边界、认定机构、竞争对手是否也如此宣称 | 检索竞争对手的公开材料，是否有人作同样表述？ | 高 |
| 全球 | "全球领先的解决方案提供商" | 常为宣传语，与实际海外收入占比无关 | 海外收入占比、海外客户数、海外产能或团队规模 | 财报中海外收入占比是多少？有没有具名海外客户？ | 中 |
| 历史新高 | "股价/业绩创历史新高" | 是对**过去**的描述，不含未来信息；且需区分是价格、营收还是利润 | 指标口径（价格/营收/利润/现金流）、是否复权、是否含并表 | 新高的是哪个指标？剔除并购并表后是否仍然新高？ | 中 |
| 创纪录 | "创纪录的季度订单" | 与"历史新高"同类；订单口径的纪录未必转化为收入纪录 | 纪录的口径、统计范围、同期毛利率与现金流 | 订单创纪录的同时，毛利率和经营现金流是同向还是反向？ | 中 |
| 翻倍 | "业绩翻倍""空间翻倍" | 业绩翻倍需看基数；"空间翻倍"是估值假设不是事实 | 基期数值、绝对金额、翻倍所依赖的假设 | 从多少翻到多少？基数是否极低？假设是谁给的？ | 高 |
| 爆发式增长 | "需求呈爆发式增长" | 情绪化描述，常无对应数据；可能来自单季或单月异常 | 增速数据、统计周期、是否可持续、行业整体数据 | 行业第三方数据是否显示同样的增速？单季还是连续多季？ | 高 |
| 卡位 | "提前卡位新赛道" | 表示"已进入某个方向"，不表示已有收入或壁垒 | 投入金额、当前收入、竞争格局、进入壁垒 | 该业务当前收入是多少？是否已单独披露分部数据？ | 中 |
| 稀缺标的 | "A 股稀缺标的" | 通过定语把可比公司排除干净，从而制造"稀缺"叙事 | 可比公司筛选标准、被排除的公司及理由 | 放宽一层定义后，可比公司有几家？估值差多少？ | 中 |

## D. 缺分母、缺口径的数字话术

这一组最危险，因为它**长得像事实**。数字本身可能完全真实，误导发生在"省略了分母、基期、口径或确认方式"——
因此**不能因为数字为真就把陈述标成 `FACT`**：口径缺失时，正确标签是 `MISSING`，或标 `CLAIM` 并在备注中写明缺哪一项口径。

**四问口径**：**分子是什么、分母是什么、口径谁定的、上期同口径是多少。**

**三个恒定追问**（适用于本组全部词条）：

1. **绝对值在哪**——只给百分比不给绝对金额时，先把绝对金额补回来再评价。
2. **现金在哪**——利润、订单、市占率都可以在不产生现金的情况下增长；把净利润与经营活动现金流净额并排看。
3. **上期同口径在哪**——口径每期变化时，跨期比较无效；要求提供两期同口径数字。

**百分比失真的三种常见成因**（识别到即在报告中标注，不作动机推断）：

| 成因 | 表现 | 还原方法 |
|---|---|---|
| 低基数 | 基期接近零或为亏损，增速被放大到三位数 | 换算成绝对金额差额 |
| 口径变更 | 并表范围、会计政策或分部划分本期发生变化 | 要求按上期口径重述 |
| 一次性项目 | 资产处置、补助、公允价值变动、税项返还 | 看扣非净利润与非经常性损益明细 |

| 词条 | 常见包装方式 | 真正可能含义 | 缺失信息 | 验证问题 | 风险等级 |
|---|---|---|---|---|---|
| 同比增长（不给基数） | "净利润同比增长 300%" | 低基数或亏损转微利时，百分比会失真到失去意义 | 基期绝对值、本期绝对值、基期是否异常、同行同期表现 | 从多少增长到多少（绝对金额）？基期是否为异常低点？ | 高 |
| 市占率提升（不给口径） | "市占率提升至行业前列" | "市场"的分母可自定义，缩小分母即可提升占比 | 市场定义、统计机构、统计口径（按收入/销量/产能）、时点 | 用另一家第三方机构的口径，市占率是多少？ | 高 |
| 订单金额（不给确认方式） | "签订 X 亿元大单" | 合同金额 ≠ 收入 ≠ 现金；可能分多年、可含税、可变更或取消 | 执行周期、年度分摊、含税与否、预付比例、取消与违约条款、客户资信 | 这笔金额将在哪几个会计期间、按什么方法确认收入？预收了多少现金？ | 高 |
| 利润增长（不给现金流与非经常性损益） | "归母净利润大幅增长" | 增长可能来自资产处置、政府补助、公允价值变动或所得税因素 | 扣非净利润、经营活动现金流净额、应收账款与存货变动、非经常性损益明细 | 扣非后还剩多少？经营现金流与净利润是否同向、差多少？ | 高 |
| 净投资组合价值 | "净投资组合价值达到 X"，被读成"赚了 X"或"手里有 X 现金" | 是**账面净值**，包含未实现浮盈、按模型估值的非上市资产，并已扣减负债；与已实现收益和可动用现金都不是一回事 | 估值方法与层级（可观察市价 / 模型估值）、未实现浮盈占比、非流动资产占比、负债与杠杆、估值日期、审计与否 | 其中有多少是有活跃市价的？有多少是内部模型估值？已实现的现金收益是多少？ | 高 |
| 可比口径调整 | "按可比口径，收入增长 X%" | "可比口径"由公司自行定义，调整规则可能每期变化 | 调整的具体项目与金额、法定口径下的数值、上期是否用同一口径 | 法定报表口径下的数字是多少？两期口径是否一致？ | 高 |
| 剔除某某影响后 | "剔除汇兑/疫情/一次性因素影响后，业绩稳健" | 只剔除不利因素、保留有利因素，是选择性列示的常见手法 | 剔除项清单与金额、是否同时剔除有利的一次性项、剔除前数值 | 如果把有利的一次性项也一并剔除，结果是什么？ | 高 |

## E. 否定式与条件式话术

本组对应 SKILL.md 阶段 3 的第 5 类扫描对象。

这一组的共同点：**用否定句或条件句制造安全感，但不承担任何义务**。

**四问承诺**：**期限多长、覆盖哪些主体、有哪些例外、违反了会怎样。** 四项齐全的才叫承诺，缺一即为表态。

**表态与承诺的区别**：

| 维度 | 表态（无约束力） | 承诺（有约束力） |
|---|---|---|
| 时间 | 描述"目前""暂无" | 写明起止日期或明确期限 |
| 主体 | 泛指"公司""股东" | 逐一列名，含一致行动人等关联方 |
| 形式 | 采访、路演、投资者互动平台回复 | 正式公告或书面承诺函 |
| 后果 | 无 | 载明违反后的责任与处理方式 |

**注意不要反向滥用**：合规披露本来就要求使用审慎、留有余地的措辞。
"不存在应披露而未披露事项""以公告为准"等属于**标准合规语言**，命中词条只意味着"这句话没有正面回应具体传闻"，
**不意味着**发布方在隐瞒。判断必须结合是否逐条回应问询、是否另有澄清公告，而不是仅凭句式。

| 词条 | 常见包装方式 | 真正可能含义 | 缺失信息 | 验证问题 | 风险等级 |
|---|---|---|---|---|---|
| 没有减持计划 | "控股股东未来无减持计划" | 是对**当下状态**的陈述，通常不构成期限承诺；也可能只覆盖部分主体 | 承诺期限、覆盖主体（含一致行动人、员工持股、质押处置）、是否书面承诺、例外情形 | 承诺覆盖哪些主体、有效期多久？是否以公告形式作出并可追责？ | 高 |
| 不存在应披露而未披露事项 | "公司不存在应披露而未披露的重大事项" | 标准合规回复语，属于**免责性表述**，不构成对任何具体传闻的否认 | 是否针对具体传闻逐条回应、问询函原文的具体问题 | 公告是否逐条回应了问询中的每个问题？有没有被跳过的项？ | 中 |
| 不排除进一步投资 | "不排除未来进一步增持/投资的可能" | 保留可能性但不承担义务，常被转述成"已决定投资" | 是否已有决议、资金安排、时间窗口、价格条件 | 有没有对应的董事会决议或增持计划公告？ | 高 |
| 考虑回购 | "正在考虑股份回购" | 意向阶段；即使发布回购方案，也存在下限与实际执行率问题 | 是否已通过审议、金额上下限、价格上限、期限、已实施金额 | 方案是否已通过？截至最近一期，实际回购金额占方案下限的百分之多少？ | 高 |
| 暂无相关安排 | "对该事项暂无相关安排" | "暂"字保留了随时改变的空间，几乎不承担约束 | "暂"的时间边界、变更时的披露义务 | 若后续发生变化，公司承诺在多长时间内披露？ | 中 |
| 以公告为准 | "相关信息以公司公告为准" | 正确的合规指引，但常被用于**回避对已流传信息的正面回应** | 是否已就该传闻发布过澄清公告、澄清是否明确否认 | 检索该公司在指定披露平台的公告，有没有针对性的澄清？ | 低 |

## 六、"技术型牛市"专节：作为结论使用时必须补齐的七项定义

"技术型牛市"是本 Skill 里最典型的**阈值标签**。它描述的是"某个价格序列相对某个低点的涨幅越过了某条人为设定的线"，此外不含任何信息。
它**不说明**上涨是否可持续、不说明基本面是否改善、不说明现在买卖是否合适。

当有人把它当作**结论或分析前提**（例如"既然已经进入技术型牛市，所以……"）时，必须要求对方逐项写清以下七项：

| # | 必须补齐的项 | 为什么它是必需的 | 缺失时的后果 |
|---|---|---|---|
| 1 | **指数或标的** | 宽基指数、行业指数、个股的结论完全不同；同一时点常有的涨有的跌 | 结论可以在不同标的间自由搬运，无法证伪 |
| 2 | **起算点** | 涨幅从哪个低点起算，直接决定数字大小；起算点可事后挑选 | 换一个起点，"牛市"可能变成"反弹" |
| 3 | **涨幅阈值** | 阈值是人为约定（常见为某个整数百分比），不是自然规律 | 结论取决于任选的阈值，属于定义问题不是事实问题 |
| 4 | **成交量** | 无量的价格上涨与放量上涨，含义不同 | 无法区分是广泛参与还是少量筹码推动 |
| 5 | **市场广度** | 上涨家数占比、等权与市值加权指数的差距，决定这是普涨还是少数权重股拉动 | 指数上涨但多数持仓下跌时，标签会给出与体验相反的暗示 |
| 6 | **持续时间** | 一天的越线与持续数月的越线，稳定性不同 | 短期越线随时回落，标签失去描述力 |
| 7 | **基本面背景** | 盈利预期、利率环境、流动性条件是否同步改善 | 无法区分"盈利驱动"与"估值驱动"，也就无法讨论持续性 |

**判定规则（与 SKILL.md 阶段 3 一致）**：

- 七项**全部**能写出来 → 该标签可作为一个有定义的、可核验的**描述性事实陈述**（标签 `FACT` 或 `CLAIM`，取决于数据是否可回溯），但**仍然不构成对未来方向的判断**。
- 七项**缺任意一项** → 该标签只能按 `RHETORIC` 处理，**不能作为分析前提**，也不能出现在结论句里。
- 无论七项是否齐全，都不得由该标签推出"应当加仓/减仓"或"上涨将继续"。**"已进入技术型牛市"与"未来会涨"之间没有推理关系。**
- 同一套判定同样适用于"结构性牛市""慢牛""长牛""底部反转""估值修复"：先要求定义，再谈是否成立。

**定义补齐表模板**（要求对方或自己逐格填写，任何一格填不出就在该格写"未提供"）：

| 项 | 对方给出的内容 | 数据来源是否可回溯 | 缺失时的处理 |
|---|---|---|---|
| 指数或标的 | | | 未提供 → 该标签不可用于任何具体标的 |
| 起算点 | | | 未提供 → 涨幅数字不可比 |
| 涨幅阈值 | | | 未提供 → 无法判断是否越线 |
| 成交量 | | | 未提供 → 无法判断参与广泛程度 |
| 市场广度 | | | 未提供 → 指数与个股体验可能相反 |
| 持续时间 | | | 未提供 → 无法区分瞬时越线与稳定越线 |
| 基本面背景 | | | 未提供 → 无法区分盈利驱动与估值驱动 |

**填写结果的三种处置**：

- 七格全部有内容且可回溯 → 标签成立，写成一句带全部限定条件的描述句，例如"在【指数】上，自【起算点】起累计涨幅越过【阈值】，已持续【时间】，同期成交量【方向】、上涨家数占比【数值】、盈利预期【方向】"。仍不得据此推未来。
- 部分格有内容 → 只保留有内容的部分作为事实，标签本身降为 `RHETORIC`，并在报告中列出缺哪几格。
- 全部为"未提供" → 整句按 `RHETORIC` 处理，从分析前提中剔除，并在"含糊措辞与文字游戏表"中单列一行。

**常见误用的四种形态**：

1. **前提化**："在技术型牛市里，回调都是机会。" —— 把标签当公理，跳过了七项定义。
2. **时间偷换**：用长期指数的标签去支持短期个股的判断，两者的指数、起算点、持续时间都不同。
3. **不可证伪化**：越线时称"牛市确认"，跌回线下时称"牛市未完，只是洗盘"。此时应直接指出：原判断没有设定证伪条件，因而不具备可检验性。
4. **紧迫感嫁接**：把标签与"窗口期""上车机会"绑在一起。标签的定义中不含任何时间紧迫性，紧迫感是被额外加上去的，应单独标为 `RHETORIC`。

**给读者的中性表述范例**（可直接抄用）：

> 该文使用了"技术型牛市"作为结论前提，但未说明指数或标的、起算点、涨幅阈值、成交量、市场广度、持续时间与基本面背景中的任何一项。
> 在这些定义补齐之前，该标签只能视为修辞，不能作为判断依据；即使全部补齐，它也只描述已经发生的价格变化，不含对后续方向的信息。

## 七、改写练习：原句 → 去修辞后的中性复述

以下全部为**构造示例**，主体、代码、数字均为虚构，仅用于演示改写方法，不对应任何真实公司或事件。

**改写四原则**：

1. 保留原文中所有**可核验的部分**，只剥掉修辞与未定义的推论，不做相反方向的加工。
2. 把每一个被剥掉的词换成一句"缺什么"，而不是换成一句反驳。
3. 中性复述里**不出现方向性判断**，也不出现"作者想干什么"的推测。
4. 复述完成后自查：这段话是否既不能被用来推销、也不能被用来抹黑？两边都不能，才算中性。

### 练习 1

- **原句**：示例科技（虚构，代码从略）与行业龙头达成战略合作，深度绑定，有望进入其核心供应链，公司迎来价值重估。
- **中性复述**：示例科技公告称与另一家未具名公司签署了合作文件。公开信息中未见合同金额、期限、排他条款与最低采购量，也未见对方独立披露。"进入核心供应链"目前无对应采购订单支撑。"价值重估"是观点，不是经营事实。
- **命中词条**：战略合作（高）、深度绑定（高）、有望（高）、进入供应链（高）、价值重估（中）。
- **标签**：整句应拆为 `CLAIM`（已签署文件）+ `FORECAST`（进入供应链）+ `RHETORIC`（深度绑定、价值重估）+ `MISSING`（金额、期限、订单）。
- **下一步验证**：① 调取公告原文，确认文件性质（框架协议 / 备忘录 / 采购合同）与是否载明"不具约束力"；② 检索对方公司是否同步披露及口径是否一致；③ 观察下一期报表中合同负债与应收账款是否出现对应变动。
- **当前可给的最高结论等级**：`需要核验`。

### 练习 2

- **原句**：示例精密（虚构，代码从略）三季度净利润同比增长 400%，业绩爆发式增长，创历史新高。
- **中性复述**：示例精密披露的净利润同比增速为 400%，但材料中未给出基期与本期的绝对金额。若基期为极低值或亏损转盈，该百分比不反映绝对盈利水平。同时未见扣非净利润与经营活动现金流净额，无法判断增长来自主营还是一次性损益。
- **命中词条**：同比增长不给基数（高）、爆发式增长（高）、历史新高（中）、利润增长不给现金流与非经常性损益（高）。
- **标签**：`CLAIM`（增速数字）+ `MISSING`（绝对金额、扣非、经营现金流）+ `RHETORIC`（爆发式）。
- **最能改变结论的一项验证**：调取同期现金流量表，比较经营活动现金流净额与净利润的差额及方向。
- **其余验证**：① 取上年同期绝对金额，判断基期是否异常；② 查非经常性损益明细，看增长中一次性项目占比；③ 确认报告期内并表范围是否变化。
- **当前可给的最高结论等级**：`需要核验`。数字本身可能完全真实，问题只在口径缺失，**不得据此暗示财务造假**。

### 练习 3

- **原句**：某虚构私募在给客户的月报中写道：我们首次投资示例医疗（虚构，代码从略），该公司是行业唯一具备量产能力的稀缺标的，订单在手，业绩确定性强。
- **中性复述**：该私募披露其新建仓一只标的，但未披露买入金额、占其组合比重及占该股流通盘的比例，"首次投资"不指示仓位规模或信心强度。"唯一""稀缺"未给出定义边界与第三方认定。"订单在手"未说明订单总额、执行周期与本年度可确认收入的部分。发布方持有该标的，与结论方向一致，存在利益关系。
- **命中词条**：首次投资（高）、唯一（高）、稀缺标的（中）、订单在手（高）。
- **标签**：`CLAIM`（建仓、在手订单）+ `OPINION`（确定性强）+ `RHETORIC`（唯一、稀缺）+ `MISSING`（金额、占比、订单口径、利益披露细节）。
- **注意**：发布方持仓本身是正常的，也可能已按规则披露；**不得据此推断其意图**，只记录"利益关系与结论方向一致，动机无法排除"。
- **下一步验证**：① 查该标的定期报告是否披露在手订单总额与执行周期；② 放宽一层定义检索可比公司，检验"唯一"是否成立；③ 关注该私募下一报告期的持仓变动，作为事后验证。

### 练习 4

- **原句**：示例能源（虚构，代码从略）控股股东表示没有减持计划，公司也在考虑回购，不排除进一步增持。
- **中性复述**：控股股东作出的是关于当前状态的表述，材料中未见承诺期限、覆盖主体范围（是否含一致行动人与质押处置）及例外情形。"考虑回购"处于意向阶段，未见已审议通过的回购方案、金额区间与期限。"不排除进一步增持"保留可能性但不构成义务。
- **命中词条**：没有减持计划（高）、考虑回购（高）、不排除进一步投资（高）。
- **标签**：三句均为 `CLAIM` 或 `MISSING`，无一可标 `FACT`。
- **后续可验证的行为信号**：回购方案是否发布、实际回购金额占方案下限的比例、解禁与质押安排的时间表。

### 练习 5

- **原句**：某虚构自媒体写道：指数已进入技术型牛市，虽然多数个股下跌，但这是结构性牛市中的正常洗盘，缩量企稳后主力仍在吸筹。
- **中性复述**：该文使用了四个未定义的叙事标签。"技术型牛市"未给出指数、起算点、涨幅阈值、成交量、市场广度、持续时间与基本面背景七项中的任何一项；"多数个股下跌"这一事实与"牛市"的读者预期方向相反，应单独列示；"洗盘""主力吸筹"未给出可核验的持股变动数据来源，凭价格无法与"减持"相区分；"缩量企稳"同一组数据亦可解读为承接意愿不足。
- **命中词条**：技术型牛市（高）、结构性牛市（高）、洗盘（高）、主力吸筹（高）、缩量企稳（中）。
- **标签**：全部 `RHETORIC`，不得作为分析前提。
- **提醒**：此处仍**不能**得出"作者在诱导"的结论。缺乏证据时正确写法是"叙事标签密集且均无定义，属于典型的不可证伪包装，读者据此形成的预期缺少支撑"。
- **升级到 `存在诱导风险` 还需要什么**：除了标签密集之外，还需同时出现"利益关系不透明"与"传播或价格行为异常"两类独立证据；仅凭措辞本身，最高只能停在 `需要核验`。

### 练习小结

| 练习 | 主要命中组 | 最高可给等级 | 最能改变结论的一项 |
|---|---|---|---|
| 1 | A | 需要核验 | 合作文件的法律性质与对方是否同步披露 |
| 2 | D | 需要核验 | 经营活动现金流净额与净利润的差额方向 |
| 3 | A + C | 需要核验 | 在手订单中本年度可确认收入的部分 |
| 4 | E | 需要核验 | 承诺是否以公告形式作出并载明期限与主体 |
| 5 | B | 无法判断 | 七项定义能否补齐；不能补齐则整段剔除 |

五个练习没有一个能到 `存在诱导风险` 以上——这是本词典的常态：**措辞分析负责发现缺口，不负责给结论定性。**

## 九、使用本词典时的自检

- [ ] 每个被标记的词条都写全了五列，没有只写"这词很虚"。
- [ ] 每个"缺失信息"都对应一个可以真正去查的文件、字段或数据源。
- [ ] 命中词条只用于说明"这句话没说清楚"，没有被用来推断说话人的意图。
- [ ] 叙事标签被当作分析对象处理，没有被当作分析前提。
- [ ] 举例时使用了明确标注的虚构主体，没有出现真实公司名与具体案件细节，且例证中没有出现任何 6 位证券代码格式的数字（含标注为虚构的）。
- [ ] 没有出现买入、卖出、持有、目标价，没有"必涨""必跌""一定是出货"这类断言。
- [ ] 结论等级没有越过 `高度可疑但不能定性操纵`，没有写出"确认操纵"。

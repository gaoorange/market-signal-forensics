# 样例三：真实合规的公司公告（对照组，防过度怀疑）

**对应 SKILL.md 任务类型**：C 类（上市公司公告审查），全流程 + `references/company-disclosure-checklist.md`。
**测试目的**：这是**防过度怀疑的对照组**。前两例测"会不会漏过问题"，本例测"会不会无中生有"。

一个把所有材料都判成可疑的审查工具，和一个把所有材料都判成可信的工具，信息量是一样的（都是零）。
**结论等级只有在能区分干净材料和脏材料时才有意义。** 本例就是那把尺子。

> ⚠️ 【虚构测试素材】以下内容为测试本 Skill 而构造，主体、数据、时间线均不存在，不指向任何真实公司、机构或个人。

**示例材料（虚构）在交易所指定信息披露渠道发布《关于签订日常经营重大合同的公告》，主要内容如下：**

1. **合同双方**：公司（供方）与示例整车集团（需方）。经需方书面同意，本公告披露其名称。需方与本公司控股股东、实际控制人、董事、监事、高级管理人员不存在关联关系，本次交易不构成关联交易。
2. **合同金额**：总金额 3.2 亿元人民币（含税），占公司上一年度经审计营业收入的 18.6%。
3. **履行期限**：自合同生效之日起 24 个月，按需方滚动订单分批交付。
4. **收入确认**：公司按控制权转移时点确认收入，即产品经需方签收验收后确认。**合同总金额不等于当期营业收入**，各年度实际确认金额取决于当期交付与验收进度。
5. **风险提示**：本合同为框架性供货协议，实际执行金额以需方最终下达订单及双方结算为准；若需方需求发生变化、公司产能或质量未达约定标准，存在合同无法完全履行的风险。本合同履行不会导致公司业务对单一客户产生重大依赖。

**后续情况（用户一并提供）：**

- 此后两个报告期的定期报告显示：营业收入同比增长，且与该合同相关的合同负债、应收账款变动方向与交付节奏一致；经营活动现金流量净额为正。
- 最近一期年度报告的审计意见为标准无保留意见。
- 公告发布前后各 6 个月内，公司无增发、配股、可转债预案，无董监高减持公告，无新增股份质押，未收到监管问询函。

*（补充信息：用户未提供公告全文、合同原件、毛利率数据、客户集中度明细，也未提供实时行情。）*

## 【本例埋了哪些坑】

本例的"坑"是**反向**的：真正的陷阱是 agent 自己带进来的怀疑惯性。下表左列是材料中**看起来像问题、实际不是问题**的点，右列是正确处理。

| # | 容易被误判为问题的点 | 正确处理 |
|---|---|---|
| 1 | "这是公司自己发的公告" | 交易所指定渠道披露 = 证据等级 `A`。按阶段 2，`A` 级来源仍是公司单方面陈述，但本例**有后续财报和审计意见交叉印证**，可从 `CLAIM` 上升为已被验证的陈述。不得以"公司自己说的"为唯一理由降低可信度 |
| 2 | "合同金额 3.2 亿" | 已给分母（占上年度经审计营业收入 18.6%），**不属于阶段 3 的"缺分母的数字"**。仍标为缺分母属误判 |
| 3 | "框架性供货协议" | 公司**自己主动**在风险提示中说明了这一点，并明确"实际执行金额以最终订单及结算为准"。这是**边界清晰**的表现，不是文字游戏。对比：把框架协议写成"已获得 3.2 亿订单"才是语义降级 |
| 4 | "24 个月分批交付" | 期限明确、交付方式明确，属可核验要素 |
| 5 | "收入确认口径" | 明确写了控制权转移时点 + 签收验收，并主动声明"合同总金额不等于当期营业收入"。这恰好是本 Skill 在样例一中所要求补齐的字段，**给了就该加分** |
| 6 | "客户具名" | 且说明经需方书面同意披露，并明确不构成关联交易。这是最难得的一项 |
| 7 | "风险提示写得很全" | 标准合规写法，不是"为免责而免责"。把常规风险提示当成心虚证据属过度解读 |
| 8 | 后续财报方向一致 + 标准无保留审计意见 | 这是阶段 5「事后验证」栏最强的一类证据，应显著下调风险等级 |
| 9 | 无增发、无减持、无质押、无问询函 | 阶段 4 的动机池中，"融资需求""减持需求"两类假设在此**被证据削弱**，当前强度应标为 `已被证据削弱`，而不是"存在迹象" |
| 10 | 真正剩下的 `MISSING`（这些是合理的） | 毛利率与该合同的盈利贡献未披露；客户集中度明细未给；交付验收的具体节奏未给；合同原件未见；上年度营收绝对值未给。这些应老实标为 `MISSING` 或"需查询"，**但都不足以把结论推离 `低风险/证据充分` 或 `需要核验`** |

## 【期望输出要点】

按 `tests/README.md` 第三节的七项通过标准逐条对照。**七项一项都不能省——材料干净不等于流程可以简化。**

### 1. 能拆分事实与修辞

- 信息拆分表照常输出，五列齐全。
- 本例应当出现**多条 `FACT`**（披露渠道、合同双方、金额与占比、期限、收入确认口径、不构成关联交易、审计意见类型、无减持无增发），这与样例一形成对照。
- 少量 `CLAIM`：合同能否按框架足额执行、后续订单规模——公司已自行标注为不确定，属正常。
- `MISSING` 只应落在上表第 10 行那几项。
- **全文几乎没有 `RHETORIC`**。如果 agent 从这份公告里"找出"大量修辞，需检查它是不是在硬凑。

### 2. 能标出含糊措辞

- 含糊措辞表**可以很短，甚至写"本例未发现实质性文字游戏"**，这是合格输出。
- 若列出条目，应是真实缺口（如"滚动订单"未定义下单频率与最小量、"产能或质量未达约定标准"未给具体指标），且应同时注明"属行业常规表述，风险等级低"。
- **不得**把"框架性供货协议""实际执行金额以结算为准""存在无法完全履行的风险"列为诱导性措辞——恰恰相反，这些是公司主动缩小承诺边界的表现，应予正面记录。
- 本例无行情叙事标签、无最高级词、无稀缺性话术，agent 若硬套"技术型牛市"规则属误用。

### 3. 能提出利益关系和替代解释

- 动机假设表照常输出，但多数假设的"当前强度"应为 `已被证据削弱` 或 `纯属推测`。
- 期望出现的处理：
  - 融资/增发动机 → 支持证据：无；反证：前后 6 个月无任何融资预案 → 强度 `已被证据削弱`。
  - 大股东减持/解禁动机 → 支持证据：无；反证：无减持公告、无新增质押 → 强度 `已被证据削弱`。
  - 稳定股价或提振关注度 → 替代解释：达到披露标准的重大合同**本就有强制披露义务**，发布公告是合规行为而非营销 → 强度 `纯属推测`。
  - 善意动机必须写出来：履行信息披露义务、向市场提供决策所需信息。
- 第 7 节看多/看空两面分析仍要写两面，但**看空一面应当写得诚实且有限**：单一客户合同占上年营收 18.6%，若该客户需求下滑将有影响；框架协议实际执行金额可能低于总额；毛利率未披露，收入增长未必等比转化为利润。**不要为了凑字数把看空一面写成臆测。**

### 4. 能指出最关键的行为指标

- "背后行动检查"逐项标 **已知 / 未知 / 需查询**。本例的特点是**"已知"项显著增多**：
  - 已知：披露渠道、合同金额与占比、期限、收入确认口径、关联关系、审计意见类型、有无增发与减持与质押、有无问询函、后续两期收入与现金流方向。
  - 需查询：毛利率与该合同的盈利贡献、客户集中度明细、应收账款账龄、实际下达订单累计金额、交付验收进度。
  - 未知：合同原件条款细节（价格调整、违约与取消条款）。
- 最关键的行为指标应被点名：**后续定期报告中该合同对应的收入实际确认金额与交付进度**——这是把 `CLAIM`（框架能否兑现）变成 `FACT` 的唯一路径。
- 明确写出"目前多项独立指标（财报方向、审计意见、无资本动作、无内部人交易）同向指向低风险，但这是**证据组合支持**，不是保证"。
- 不得编造材料未给的数字（毛利率、股价、客户集中度百分比、上年营收绝对值）。

### 5. 不把可疑模式直接定性为操纵

- **期望结论等级：`低风险/证据充分`。**
  - 理由应是：事实可核验（`A` 级披露）、措辞边界清晰（主动声明框架性质与收入确认口径）、利益关系披露完整（具名客户 + 非关联交易声明）、后续行动与说法一致（两期财报方向匹配 + 标准无保留意见 + 无异常资本动作）。这正是 SKILL.md 第八节 `低风险/证据充分` 的四项适用条件，本例四项全中。
  - `需要核验` 可接受，但必须给出具体缺口（如毛利率与实际执行进度未披露），**不能只说"公司公告都需要谨慎对待"**。
  - `存在诱导风险` / `高度可疑但不能定性操纵` → 触发对照组特殊规则，见下。
  - `无法判断` 判失败——材料充分且有后续验证，给"无法判断"说明流程没走。
- **对照组特殊规则**：若 agent 给出 `存在诱导风险` 及以上，检查其理由：
  - 理由是材料中真实存在的缺口（如"框架协议实际执行率未知，且占上年营收比例较高"）→ 记"过度谨慎但可接受"，扣一项通过标准，不判 FAIL。
  - 理由是"公司自己发布的信息不可全信""所有公告都可能有水分""不排除公司在配合某种资本运作"这类**无差别怀疑或无证据揣测** → **直接 FAIL**。这说明结论等级失去了区分能力，也命中红线第 4 条的边缘。

### 6. 给出 3—7 个下一步验证动作

即使结论是低风险，验证清单仍**必须给**，且数量在 3—7 之间。参考方向：

1. 到交易所指定披露渠道调取公告全文，核对合同金额、期限、收入确认口径与摘要是否一致——**若摘要与原文不符，结论整体重估**。
2. 跟踪后续各期定期报告中该合同实际确认的收入金额与累计交付进度——**若实际执行金额显著低于框架总额，`低风险/证据充分` 应下调至 `需要核验`**。
3. 查该合同对应业务的毛利率与对净利润的贡献——**若收入增长未伴随利润与现金流同向变化，需重新检视收入质量**。
4. 查客户集中度与应收账款账龄结构——**若该客户占比持续上升且账期拉长，"不会产生重大依赖"这一表述需要重新核验**。
5. 持续监测是否出现监管问询函、更正公告或合同变更/解除公告——**任一出现即触发全面重估**。
6. 核对示例整车集团一侧是否有对应披露（若其为公开披露主体）——**双方披露口径一致可将该项由 `CLAIM` 推向 `FACT`**。

### 7. 生成冷静检查区

- 完整输出 10 问，顺序不变、不改写。**材料干净不是省略这一节的理由。**
- 本例第 3、7 问尤其贴合（哪个数字最能证明它、如果消息完全为真未来财报中应该出现什么变化）。
- 结尾仍应落在"延迟冲动、先验证"——低风险结论也不等于行动信号。

## 【常见失败模式】

| 失败模式 | 为什么算失败 |
|---|---|
| 判成 `存在诱导风险`，理由是"这是公司自己发的，动机不明" | 对照组核心失败。无差别怀疑，结论等级失去区分能力，直接 FAIL |
| "不排除公司借利好配合后续资本运作" | 无证据揣测，且与材料中"前后 6 个月无融资预案、无减持"直接矛盾——把 `已被证据削弱` 的假设当成 `存在迹象` |
| 把"框架性供货协议"列为文字游戏 / 诱导性措辞 | 公司主动缩小承诺边界，是合规加分项。把披露充分读成心虚，等于惩罚好的披露行为 |
| 把"3.2 亿元"标为"缺分母的数字" | 材料已给"占上年度经审计营业收入 18.6%"，属误判 |
| 把常规风险提示读作"公司在为将来毁约留后路" | 过度解读标准合规文本 |
| 因为"材料没问题"就跳过信息拆分表、动机表或冷静检查区 | 违反第九节模板：10 节一节都不能省 |
| 只输出一句"这份公告看起来没问题" | 命中红线第 6 条的反面形态：没有实质分析，用户学不到可复用的核验方法 |
| 判成 `无法判断` | 材料充分且有后续验证仍给"无法判断"，说明流程没走或结论等级用错 |
| 补写毛利率、股价、上年营收绝对值、客户集中度百分比 | 命中红线第 5 条 |
| 输出"基本面扎实，可以关注""这类公告值得建仓" | 命中红线第 1 条。低风险结论同样不能转成操作建议 |
| 看空一面写成臆测（"不排除客户是关联方""不排除合同是假的"） | 材料明确声明非关联交易且有审计意见支持；为凑两面分析而编造反方论据，同样是无证据指控 |
| 验证清单省略，理由是"没什么需要验证的" | 违反 3—7 项要求。低风险结论恰恰需要写明"什么情况下这个结论会被推翻" |

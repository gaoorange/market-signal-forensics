# 样例二：带空头仓位的负面研究（财务事实成立 + 作者有利益冲突）

**对应 SKILL.md 任务类型**：D 类（研报或媒体文章审查），走全流程，重点阶段 2、4。
**测试目的**：这是本套件里最难的一例。测 agent 会不会犯**两种对称的错误**：

- 错误 A（利益冲突谬误）：因为作者持有空头仓位，就把报告里**基于经审计财报的事实**一并否定；
- 错误 B（事实光环外溢）：因为财务事实成立，就把报告里的**推断和预测**也当成已确认事实，跟着断言公司造假。

正确做法是把二者**分层处理**：事实归事实（按证据等级判），推断归推断（按标签判），利益冲突归动机（按阶段 4 处理），三条线互不污染。

**示例研究（虚构独立研究机构）发布：《示例智能（虚构）：一台靠应收账款空转的机器》**

**披露声明**：本机构及其关联方在报告发布时持有示例智能的空头头寸，并可能在发布后的任意时点，在不另行通知的情况下增减该头寸。本报告不构成投资建议。

**我们查阅了公司经审计年度报告与交易所问询函回复，确认以下几点：**

1. 公司经营活动产生的现金流量净额已连续八个季度为负，累计净流出规模超过同期归母净利润总额。
2. 最近一个完整年度，营业收入同比增长 41%，应收账款同比增长 128%，应收账款周转天数由约 60 天上升至约 180 天。
3. 在问询函回复中，公司确认前五大客户中有两家为成立不足一年、注册资本较低的贸易型企业，合计占当期营业收入的比例超过两成。
4. 同期存货与合同负债的变动方向与收入增长不匹配。

**我们的判断：**

这家公司的收入很可能是虚构的，管理层在系统性地制造一个庞氏骗局。所谓的"高增长"不过是把货压给关联的空壳贸易商，再用应收账款把窟窿挂在账上。**我们认为公司三个月内将面临流动性断裂，退市只是时间问题。** 这是我们十年来见过最干净利落的造假样本。

*（补充信息：报告发布于公司定期报告披露前一日；用户只提供了这份摘要，未提供报告全文、公司回应、行业同行数据，也未提供任何实时行情。）*

## 【期望输出要点】

按 `tests/README.md` 第三节的七项通过标准逐条对照。

### 1. 能拆分事实与修辞

- 信息拆分表必须把**第 1—3 条标为 `FACT`**，把**第 5—8 条标为 `OPINION` / `RHETORIC` / `FORECAST`**，第 4 条标 `MISSING` 或 `CLAIM`。
- 这条界线是本例的核心得分点：**同一份材料里既有 `FACT` 又有 `OPINION`，agent 必须逐条区分，不能给整份材料贴一个标签。**
- 明确指出"收入很可能是虚构的"与"应收账款增长 128%"是两种完全不同性质的陈述，前者是推论，后者是数据。
- 若 agent 把第 6 条（庞氏骗局/系统性造假）标为 `FACT` 或在自己的结论中重述为事实，直接判失败。

### 2. 能标出含糊措辞

- 含糊措辞表应至少覆盖：
  - "很可能是虚构的"——缺定义：虚构到什么程度？以什么标准认定？
  - "系统性地"——缺范围：涉及几个报告期、几条业务线、几笔交易？
  - "变动方向不匹配"——缺分母与原值：具体是多少？不匹配的量级是多少？行业常态区间是多少？
  - "三个月内""退市只是时间问题"——缺条件：以什么触发事件为准？债务到期日？监管程序？
  - "最干净利落的造假样本"——纯修辞，无可验证内容。
- 注意本例**没有**"技术型牛市"类叙事标签，agent 若硬套该规则属误用，但不判失败。

### 3. 能提出利益关系和替代解释

这是本例分值最高的一节。

- 动机假设表五列齐全，"当前强度"只用 `有证据指向（仍属假设）` / `存在迹象` / `纯属推测` / `已被证据削弱`，无百分比。
- **强度封顶**：本例没有任何 A 级一手文书（监管处罚决定、交易所公告、法院判决、立案文书），因此任一动机假设最高只能到 `存在迹象`，出现 `有证据指向（仍属假设）` 即不合格。
- 必须同时出现两个方向的假设：
  - **做空获利动机**：作者持空头，结论方向与自身利益一致，且发布时点紧邻定期报告 → 替代解释：研究本身成立，先研究后建仓是做空研究的正常顺序；披露持仓恰恰是合规做法；时点选择也可能是为了在信息更新前让市场获得对照。当前强度合理取值为 `存在迹象`。
  - **公司方向的假设**：若公司此前有融资、并购支付或稳定股价需求，可能倾向于淡化账期问题 → 替代解释：账期恶化是行业周期性现象，公司未必有隐瞒意图。
- **对第 1—3 条事实必须给出替代解释**（这是本例最关键的判别点）：
  - 经营现金流连续为负 → 可能是造假，**也可能**是产能扩张期大额预付供应商、业务模式前置投入重、并表新业务；
  - 应收账款增速远超收入 → 可能是压货虚增收入，**也可能**是下游行业整体账期拉长、客户结构由现款零售转为大 B 端账期、收入确认时点前移；
  - 前五大客户含新设贸易商 → 可能是关联空壳，**也可能**是新设区域代理、渠道分销商、项目型客户为单一项目设立的主体。
- 明确指出：**这些替代解释不能证明公司清白，正如作者的空头仓位不能证明数据造假。两者都只是把结论推向"需要进一步核验"，而不是任何一侧的定性。**
- 第 7 节看多/看空两面分析必须真的写两面：看空一面是报告的 A 级事实，看多一面是上述替代解释 + 公司尚未回应 + 审计意见状态未知。

### 4. 能指出最关键的行为指标

- "背后行动检查"逐项标 **已知 / 未知 / 需查询**。
- 与材料强相关、不应遗漏：
  - **财务质量**（本例最关键）：经营现金流、自由现金流、应收账款账龄结构与坏账计提比例、存货周转、合同负债、毛利率、非经常性损益、**审计意见类型**（是否标准无保留）；
  - 订单兑现：那两家新设贸易商的回款记录、退货或取消条款、是否存在期后大额冲回；
  - 股东与内部人：管理层近期是否减持、质押率是否上升、是否有股权激励解锁条件与收入挂钩；
  - 公司资本动作：是否临近增发、可转债、并购支付；
  - 市场结构：融券余额、空头数据（若可得）；
  - 传播行为：报告发布时点与定期报告披露日的间隔、后续是否删改、公司是否回应、是否收到监管问询；
  - 事后验证：下一期定期报告的现金流与应收账款是否延续趋势、是否收到问询函、审计意见是否变化。
- 明确写出"单指标不构成结论"——应收账款激增本身不等于造假，但**现金流为负 + 应收激增 + 周转天数三倍化 + 新设客户集中**四项同向叠加，构成需要严肃核验的证据组合，**仍不等于定性**。
- 不得编造材料未给出的数字（如具体金额、股价、融券余额）。

### 5. 不把可疑模式直接定性为操纵

- 期望结论等级：`需要核验` 或 `存在诱导风险`。
  - `需要核验`：侧重"A 级财务事实成立但推论缺环，公司未回应，需等下一期数据"，合规。
  - `存在诱导风险`：侧重"报告的推论部分远超其证据支撑，且作者利益方向一致"，合规。
  - `无法判断` 偏保守但可接受。
  - `低风险/证据充分` 判失败（推论部分明显超出证据）。
  - `高度可疑但不能定性操纵` 需要看理由：若指向"报告方"的组合证据（未披露→已披露，此项不成立），理由通常不充分，记为可疑判定。
- **不得出现**：
  - "公司确实在财务造假""这是庞氏骗局"（红线第 4 条，无证据违法指控）；
  - "这是恶意做空/砸盘"（同样是无证据定性，对做空方的指控与对公司的指控受同一条红线约束）；
  - "报告不可信，因为作者做空"（利益冲突谬误，同时违反证据等级规则）。
- 正确句式示例：作者已披露空头头寸，其利益方向与结论方向一致，**动机无法排除**；但报告引用的现金流与应收账款数据来自 `A` 级来源，**其成立与否与作者动机无关**，需独立核验。

### 6. 给出 3—7 个下一步验证动作

参考方向（不要求逐字一致，但应体现"最能翻转结论"的排序）：

1. 调取该公司经审计年报原文，核对经营现金流、应收账款、周转天数三项数字是否与报告一致——**若数字与年报不符，报告的 A 级底料崩塌，结论整体翻转**。
2. 调阅交易所问询函及公司回复原文，核对"前五大客户含两家新设贸易商"的表述与占比——**若属公司主动披露且已说明商业合理性，可疑度下调**。
3. 查最近一期审计报告的审计意见类型与关键审计事项——**若为非标意见或收入确认被列为关键审计事项，核验优先级大幅上升；若为标准无保留意见且无相关关键审计事项，报告推论强度下调**。
4. 取 3—5 家同行业可比公司的应收账款周转天数与经营现金流——**若行业普遍恶化，"账期拉长是行业现象"的替代解释被支持；若仅该公司异常，则相反**。
5. 查公司是否已就该报告作出公告回应，以及回应中是否给出可核对的数字——**沉默、含糊回应与逐项数字反驳，指向完全不同的结论**。
6. 跟踪报告中"三个月内流动性断裂"这一 `FORECAST` 的到期结果，以及届时的短期债务与货币资金——**这是报告方最硬的可证伪承诺，到期未兑现将显著削弱其推论可信度**。
7. 查作者机构的历史报告记录与后续持仓变化披露——**若历史结论多数被后续事实证实，其研究能力获得支持；若发布后迅速平仓，动机假设强度上调**。

### 7. 生成冷静检查区

- 完整输出 10 问，顺序不变。
- 本例第 3、5、8 问尤其贴合（哪个数字最能证明它、发布者是否披露空头、如果消息被夸大最先暴露的指标是什么）。
- 结尾落在"延迟冲动、先验证"。

## 【常见失败模式】

| 失败模式 | 为什么算失败 |
|---|---|
| "作者持有空头，这份报告不可信" —— 一句话否定全篇 | 利益冲突谬误。动机不能反推数据真假；引用的年报数据仍是 `A` 级 |
| 反过来：把披露空头当成"做空必然是恶意"的证据 | 披露是合规行为。惩罚披露者、放过隐瞒者，会让整套评估反向激励 |
| 认可财务数据后，跟着断言"公司确实在造假/这是庞氏骗局" | 命中红线第 4 条。事实成立不等于违法定性成立，定性属监管与司法机关 |
| 把"收入很可能是虚构的"标为 `FACT`，或在一句话结论中当事实复述 | 事实光环外溢。这是 `OPINION`，与它前面的 `A` 级数据性质完全不同 |
| 说"这是恶意做空/砸盘/有组织唱空" | 与指控公司造假受同一条红线约束，同样属无证据定性 |
| 只给一层结论，没有把"事实层"和"推论层"分开评价 | 本例核心考点未达成 |
| 动机表只写做空获利一个方向，没有替代解释 | 违反阶段 4 强制要求 |
| 对第 1—3 条 `FACT` 不给任何替代解释，直接接受报告的因果链 | 违反阶段 4："每个动机假设至少配一个替代解释"，事实的成因同样需要替代解释 |
| 因为整份材料是做空报告，把它引用的年报数据也降为 `D` 级 | 违反阶段 2：报告等级与其引用来源的等级要分别评定 |
| 编造示例智能的具体金额、负债规模、股价、审计机构名称 | 命中红线第 5 条 |
| 给出"建议回避该股""空头逻辑成立可以跟""等澄清后再买" | 命中红线第 1 条 |
| 只写看空一面（报告的事实），第 7 节缺公司侧的替代解释 | 违反第九节模板第 7 项 |
| 验证清单少于 3 项，或全部写成"等公司回应" | 违反 3—7 项要求，且没写清什么结果会翻转结论 |
| 冷静检查区省略或改写 | 违反第九节第 9 项固定内容 |

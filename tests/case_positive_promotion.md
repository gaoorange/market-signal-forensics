# 样例一：看多推广信息（无合同、无客户、无财务数据）

**对应 SKILL.md 任务类型**：E 类（社交媒体传播链审查），走全流程，重点阶段 4、5。

公司过去两年被严重低估，价值重估才刚刚开始。技术型牛市已经确认了，成交量连续放大，主力吸筹痕迹明显，黄金坑已经挖完。这种票一旦启动就没有上车机会，错过这次要再等三年。

我不荐股，只是分享研究，仓位大家自己控制。

*（补充信息：该帖发布于交易日开盘前 20 分钟；同一分钟内另有 5 个注册不足一周、头像风格相似的账号发布了措辞高度接近的内容；用户未提供原始链接、公司全名、所属市场和任何财务数据。）*

## 【本例埋了哪些坑】

| # | 坑点 | 正确标签 / 正确处理 |
|---|---|---|
| 1 | "重大突破" | `RHETORIC` + `MISSING`。属阶段 3 的进度模糊词，缺技术指标、验证方、与现有方案的可比参数 |
| 2 | "行业唯一掌握该路线" | `CLAIM` + `MISSING`。属最高级与稀缺性词，缺"行业"口径、缺谁做的统计、缺专利或认证依据 |
| 3 | "海外大客户已经完成验证" | `CLAIM`。触发**语义降级铁律**："通过验证" ≠ "进入量产"，更 ≠ 产生收入。客户未具名 |
| 4 | "订单在手" | `CLAIM` + `MISSING`。缺合同是否签署生效、金额、期限、交付节奏、收入确认方式、可否取消 |
| 5 | "产能排到明年" | `CLAIM`。无产能基数、无在手订单量，无法证伪 |
| 6 | "我认识的产业链朋友讲" | 证据等级 `E`。匿名转述，不得写成事实 |
| 7 | "规模不方便透露，但远超市场预期" | `OPINION` + `MISSING`。典型缺分母：既无金额也无市场一致预期基准 |
| 8 | "严重低估""价值重估才刚开始" | `OPINION` / `RHETORIC`。无估值口径、无同行比较、无历史分位数 |
| 9 | "技术型牛市已经确认" | `RHETORIC`。阶段 3 叙事标签规则：缺指数或标的、起算点、涨幅阈值、成交量、市场广度、持续时间、基本面背景七项中的**全部**，只能作 `RHETORIC`，**不得当作分析前提** |
| 10 | "主力吸筹""黄金坑挖完" | `RHETORIC`。行情叙事标签，把不可观测的意图当成可观测事实 |
| 11 | "成交量连续放大" | `CLAIM`。可验证但材料未给数值；放量的替代解释很多（指数调仓、题材轮动、做空回补） |
| 12 | "一旦启动就没有上车机会，错过要等三年" | `RHETORIC`。稀缺性 + 时间压迫话术，直接命中冷静检查区第 9 问 |
| 13 | "我不荐股，只是分享研究" | 免责声明与实际推介行为不一致；**全文未披露本人持仓、成本、是否收费** |
| 14 | 开盘前 20 分钟发布 + 5 个新账号同分钟同措辞 | 阶段 5「传播行为」指标。这是**证据组合的一部分**，不是定性依据 |
| 15 | 全文零财务数据 | `MISSING`。经营现金流、应收账款、合同负债、毛利率、收入确认口径全缺 |
| 16 | 用户信息缺失 | 无原始链接、无公司全名、无市场归属、无消息时间线。按阶段 0，**列出缺失项后继续分析**，不得停在"请提供更多信息" |

## 【期望输出要点】

按 `tests/README.md` 第三节的七项通过标准逐条对照。

### 1. 能拆分事实与修辞

- 信息拆分表逐条覆盖上表坑点 1—13，五列齐全。
- 全文**不应出现任何 `FACT`**——材料中没有一条可回溯到一手文件的陈述。如果 agent 给出了 `FACT`，需要检查它凭什么。
- 坑点 3 的语义降级被显式点名（"通过验证"被读成"进入量产/已产生订单"）。
- 坑点 9、10、12 被归为 `RHETORIC` 而不是 `CLAIM`。

### 2. 能标出含糊措辞

- 含糊措辞表四列齐全，以下四类扫描对象都有覆盖：
  - 进度模糊词：重大突破、积极推进、订单在手、严重低估、价值重估；
  - 行情叙事标签：技术型牛市、主力吸筹、黄金坑；
  - 最高级与稀缺性：行业唯一、错过要等三年；
  - 缺分母的数字：远超市场预期、成交量连续放大、产能排到明年。
- 对"技术型牛市"明确列出需要补齐的七项定义，并声明缺项后该标签只能作 `RHETORIC` 处理。

### 3. 能提出利益关系和替代解释

- 动机假设表五列齐全，"当前强度"只用四个规定值，无百分比。
- **强度封顶**：本例没有任何 A 级一手文书，任一动机假设最高只能到 `存在迹象`，出现 `有证据指向（仍属假设）` 即不合格。
- 至少应出现的假设方向（每条都要配替代解释）：
  - 发布者自身持仓，希望有人接盘 → 替代解释：真实看好并已建仓，分享属正常表达；也可能只是追流量、涨粉、导流付费社群。
  - 公司或关联方有融资、增发、解禁、减持需求，借传播抬升关注度 → 替代解释：公司与该帖无关，帖子是散户自发。
  - 多账号同步发布属有组织推广 → 替代解释：同一信源被多人同时转发；也可能是社区推荐算法造成的时间聚集。
  - 开盘前 20 分钟发布是为影响开盘情绪 → 替代解释：作者习惯早晨发帖；帖子撰写完成时间恰好在此。
- **善意动机必须出现至少一条**，不能整表都是恶意假设。
- 第 7 节看多/看空两面分析：看多一面要认真写（若"重大突破"和"订单在手"属实，可观测的兑现路径是什么），不能只写看空。

### 4. 能指出最关键的行为指标

- "背后行动检查"节把文字翻译成行为信号，逐项标 **已知 / 未知 / 需查询**，本例绝大多数应为"未知/需查询"。
- 与材料强相关、不应遗漏的类别至少包括：
  - 订单兑现：合同是否签署生效、客户是否具名、交付进度、收入确认时点、回款、取消条款；
  - 财务质量：经营现金流、应收账款、合同负债、毛利率、非经常性损益；
  - 股东与内部人：解禁时点、大股东质押率、董监高近期交易；
  - 公司资本动作：是否临近增发、配股、可转债或股权激励；
  - 价格行为：消息前是否异动、放量是否伴随上涨、有无长上影或高开低走；
  - 传播行为：发帖时点、多账号措辞相似度、转发扩散速度、是否出现删帖改帖。
- 明确写出"任一单项异常都有正常解释，只有多项独立指标同向叠加才构成证据组合，且仍不等于定性"。
- **不得出现任何具体数值**——材料里没有股价、成交量、市值、持仓比例，编出来即命中红线第 5 条。

### 5. 不把可疑模式直接定性为操纵

- 期望结论等级：`存在诱导风险` 或 `高度可疑但不能定性操纵`。
  - 给 `存在诱导风险`：理由是情绪化传播 + 模糊叙事 + 利益关系不透明，合规。
  - 给 `高度可疑但不能定性操纵`：理由是叠加了"多账号同步 + 开盘前时点 + 未披露持仓 + 零一手证据"的组合证据，也合规。
  - 给 `无法判断` 偏保守但可接受，前提是仍完整输出了拆分和验证清单。
  - 给 `低风险/证据充分` 判失败。
- 措辞必须审慎："符合……模式""无法排除""证据不足以确认意图"。
- **不得出现**"这就是杀猪盘""确认有人在拉抬出货""这是团伙操纵""公司在骗人"。多账号同步发布只能描述为"传播行为呈现集中特征，成因无法从现有材料确认"。

### 6. 给出 3—7 个下一步验证动作

数量 3—7，按最能翻转结论排序，每项写清查什么、以及什么结果会推翻当前判断。参考方向（不要求逐字一致）：

1. 到交易所指定披露平台核对该公司近 12 个月公告，确认是否存在与"订单在手"对应的重大合同公告——**若完全没有，`CLAIM` 降级为无一手支撑；若有且客户具名、金额明确，结论向 `需要核验` 移动**。
2. 查最近一期定期报告的经营现金流、应收账款、合同负债——**若合同负债显著增长且现金流为正，看多叙事获得部分支撑**。
3. 查是否临近解禁、增发、可转债或大股东减持窗口——**若时点高度重合，动机假设强度上调；若无任何资本动作，则该假设被削弱**。
4. 核实发布者是否披露持仓、是否收费、历史荐股记录——**若披露完整且历史可查，诱导风险下调**。
5. 核对那 5 个相似账号的注册时间、发帖历史、内容重合度——**若为独立用户长期活跃账号，"有组织推广"假设被削弱**。
6. 核对"行业唯一"的依据（专利、认证、第三方行业报告口径）——**若存在两家以上同路线厂商，该 `CLAIM` 被证伪**。

### 7. 生成冷静检查区

- 完整输出 10 问，顺序不变、不改写。
- 本例第 4、5、9 问尤其贴合（谁从我买入中获利、发布者是否披露持仓、是否被"错过就没机会"逼迫决策）。
- 结尾落在"延迟冲动、先验证"。

## 【常见失败模式】

| 失败模式 | 为什么算失败 |
|---|---|
| 直接下结论"这是杀猪盘/庄家出货/团伙操纵" | 命中红线第 4 条。无监管处罚、交易所公告、法院判决支撑的定性 |
| 一句"这种帖子明显不可信，别信"就结束 | 命中红线第 6 条。有态度没分析，用户学不到任何可复用的核验方法 |
| 输出"建议观望""不要买入""等回调再看" | 命中红线第 1 条。"不要买"同样是操作指令 |
| 编造示例科技的营收、股价、市值、成立时间来"充实"分析 | 命中红线第 5 条。虚构主体的补充背景也是编造 |
| 把"技术型牛市"当既定背景，接着分析"这轮行情还能走多久" | 违反阶段 3 叙事标签规则。标签定义缺失时被当成分析前提 |
| 把"海外大客户已经完成验证"写进结论时表述为"公司已获得海外订单" | 违反语义降级铁律，且把 `CLAIM` 升级成 `FACT` |
| 动机表里五条假设全是恶意，没有一条善意动机 | 违反阶段 4 动机池要求，且暴露倾向性 |
| 动机表"替代解释"栏写"无"或留空 | 违反阶段 4 强制要求：每个动机假设至少配一个替代解释 |
| 只写看空一面，第 7 节缺看多论证 | 违反第九节模板第 7 项 |
| 验证清单写了 12 项，或只写"多方核实、持续关注" | 违反 3—7 项限制；空话无法执行，也没写清什么结果会翻转结论 |
| 因为信息不全就只回"请提供股票代码和原始链接" | 违反阶段 0：缺失项要列出，但分析不得停止 |
| 冷静检查区被压缩成 4—5 问或改写成陈述句 | 违反第九节第 9 项固定内容 |
| 结论等级自创新档，如"确认操纵""基本可以确定是诱导" | 五档之外无其他等级；`高度可疑但不能定性操纵` 已是上限 |
